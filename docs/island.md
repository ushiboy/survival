# 島の設計

島は毎回同じ形です。大まかな形は手で描いた **設計図** で決め、特別な場所は手で置き、木や石などの細部は固定のシードで自動で置きます。

今のマップは島全体のうちの一部（南の浜辺とその北の森、川の向こうの西の海岸、崖の上の高台と湖）で、これから設計図を描き足して広げていきます（島全体で最初のエリアの50倍以上の予定）。島の中央には火山を置き、中央へ向かうほど高くなる山道にする予定です。

## 設計図

設計図は [`wasm/src/world/island_plan.txt`](../wasm/src/world/island_plan.txt) にある文字の地図です。1文字が 4×4 マスに当たります。行の長さはすべてそろえます。設計図の文字数がそのままマップの広さになります（今は 52×34 文字＝208×136 マス）。

| 文字 | 地面 |
|---|---|
| `~` | 深い海 |
| `-` | 浅瀬 |
| `.` | 砂浜 |
| `,` | 草地 |
| `T` | 森 |
| `#` | ジャングル（茂みの藪） |
| `^` | 崖の上の高台 |
| `B` | 竹林（地面は森と同じ高さの草地） |
| `b` | 崖の上の竹林（高台の層。地面は高台の草地） |
| `W` | 崖の上の湖の深い所（高台の層） |
| `w` | 崖の上の湖の浅瀬（高台の層） |
| `s` | 崖の上の湖の岸の広い岸辺（高台の層） |
| `R` | 崖の上の岩山（高台の層。木に覆われた、登れない山） |

- 文字ごとに高さが決まっていて（深い海 -8、浅瀬 -2.5、砂浜 3.5、森 11、草地 12、ジャングル 24）、文字と文字の間はなめらかにつなぎます。
- そこへノイズを足して、海岸線やジャングルの縁を自然な曲線にします。升目のカクカクは見えません。沖ではノイズを弱めて、海の真ん中に浅瀬ができないようにしています。
- 浅瀬から沖へは、海底が1マスに高さ1より急に深くならないようにならします。浅瀬と深い海は別のパレットで描くので、急に深くなると境目がマスに沿って四角くなるためです。
- 森は草地と同じ地面で、広葉樹が多く生え、茂みが少しあります。歩いて抜けられます。ジャングルは茂みが密に生えた藪で、ほとんど通れません。
- 竹林は草地と同じ地面で、竹が1本ずつ立ちます。`B` と `b` の範囲をなめらかにつなぎ、ノイズで縁を揺らして、竹林のマスを決めます。竹林の中には木（広葉樹・松）・茂み・花を生やしません（下の「細部」を参照）。
- 1文字だけの浅瀬や砂浜は、つなぎ方によっては周りに溶けて消えたり、隣とつながったりします。描いたら下の確認ツールで形を見て調整します。

### 高台と崖

`^`・`W`・`w`・`s`・`R` は、ほかの地面とは別の層（高台の層）です。

- 高台の層の文字の範囲をなめらかにつなぎ、ノイズで縁を揺らして、高台のマスを決めます。高台は北の端から切れ目なく続くようにし、1マス幅のすき間は埋めます。
- 高台の縁のマスは **崖の縁** です。南へ落ちる所では、縁の下の3マスが **崖の岩肌** になります。東西へ落ちる所は、縁のマスが岩の側面になります。側面は上から見下ろした形で、落ちる側に幅4〜6pxの砂岩の帯を描き、帯の内側の縁に草をかぶせ、残りは高台の草です（BG1 の帯の外を透明にし、BG2 に草を描く）。マス全体を岩にすると、細い岬などで草地の中を岩の筋が走って見えたためです。崖の縁と岩肌は通れないので、崖の上へは上がれません（崖が途切れた「西の草の坂」を除く。「特別な場所」を参照）。
- 斜めに走る崖は、マスごとに段になります。段の内側の角（上と横が岩肌の地面のマス）は、岩肌の続きで斜めに埋めます。崖の足元が段ではなく斜めの線になり、線は1pxほど揺らいで定規で引いたように見えないようにしています（BG2 に岩のパレットで描き、BG1 の地面をその形に切り抜いて、足元に細い影を落とす）。当たり判定も斜めの線に合わせていて、埋めた岩の側には入れません（主人公の足元が斜めの線で止まる）。埋める角は島を作るときに決めます。波打ち際や川の岸のそば、木や茂みのあるマスは埋めず、埋めたマスには枯れ枝・石・蟹を置きません。
- 高台の下の地面は、高台の層のいちばん近く（南を先に見る）に描いた文字の地面が続いていることにします。北の崖の下は森、海に張り出した岬の下は深い海になり、断崖が海に直接落ちます。
- 崖の岩肌は黄土色の砂岩で描きます（岩のパレットの砂の色と茶色）。ゆるく揺れる地層の横じま、上から垂れる雨の筋、下の方の柔らかい形のくぼみがあり、崖の上の草や茂みが丸い塊で縁から垂れ下がります。上から見た崖の側面や、くぼみの左右の壁も同じ砂岩の色です。岩肌の模様は64pxごとに繰り返すので、崖のマスどうしで絵を使い回せます。
- 崖の足元には岩くずを置きません。草地に立つ所では、長さのそろわない草が足元にかぶさって伸びます（BG1 の岩肌のその部分を透明にし、BG2 に草を描く。岩のパレットには緑が1色しかないため）。砂浜に立つ所では、岩が地面に接する所を暗くするだけです。水に落ちる所は、水に洗われる明るい色を混ぜます。
- 崖を斜めに走らせるときは、`^` の縁を1行に1文字ずつずらします（45度）。それより急な斜め（2行に1文字など）にすると、南向きの岩肌がとぎれとぎれになり、崖がつながって見えません。
- 高台の草地は、そばに砂のマスがなければ砂浜との境目を描きません（高台の高さは海に近い所で低くなるので、海辺の草地と同じように砂の縁が出て、草地の中に明るい筋が走って見えたため）。湖の岸辺の砂とは、海辺と同じように境目を描きます。
- 高台の上には茂みと木を密に置きます。高台の木は8割が松で、残りが広葉樹です（低い所は広葉樹、高い所は針葉樹）。高台へは、崖のくぼみにハシゴを立てると上がれます。

### 崖の上の湖と岩山

- 高台の層にも高さがあり（`^`・`R` 12、`s` 3.5、`w` -2.5、`W` -8）、下の地面と同じようになめらかにつないでノイズを足します。水際（0）より低い所が湖で、深い所・浅瀬・岸は海と同じ高さの区切りで決めます。深い所が乾いた地面に直接触れないように浅瀬をはさみ、水に触れる高台の草は岸（地形は砂浜と同じ扱い）にします。
- 湖は1つにまとめます。ノイズで湖から切り離された小さな水たまりは、岸で埋めます（竹筏を出す岸の上に池ができてまぎらわしかったため）。
- **土壌**: マスごとに土壌（`Soil`。砂か湿った土）を持ちます。湖の岸と湖底のマスは湿った土です。地形の扱い（歩けるか、何を置くか）は変わらず、描き分けに使います。
  - 湿った土は、岩のパレットの茶色と苔の色で描きます（まだらの茶色に苔と小石）。水際ほど暗く湿って見えます。
  - 浅瀬や草のパレットには茶色がないので、水際や草との境目のマスは、BG1 の土の部分を透明にし、BG2 に土を描きます。そのため、岸に接する高台の草には木・茂み・花を置きません（木の葉も BG2 に描くので重なる）。
  - 湖の水際には、海の白い波の泡を描かず、水が土に触れる所に淡い線を引くだけです（湖には波がほとんどない）。
- **岩山**: `R` の範囲をなめらかにつなぎ、ノイズで縁を揺らして岩山のマス（`Terrain::Crag`）を決めます。岩山は通れない地形です。
  - 上の面は、木や茂みの葉の塊がこんもり重なった緑で描きます（木の葉のパレット）。南の縁の下には、崖と同じ砂岩の岩肌が3マス切り立ちます（地形は崖と同じ）。岩山が高台の崖の縁（`CliffTop`）のすぐ上で終わっていて、下に岩肌を立てる地面がない所では、代わりに岩山の下の端の3マスを岩肌にします。岩山が崖の上の大地から立ち上がって見えるようにするためです（岩肌がないと、岩山の上の面が崖の縁にそのまま載って見えた）。
  - 岩山は段々に高くなります。縁からの距離（斜めは1.4と数え、マップの端も縁とする）に、大きくゆるやかなノイズを足し、4マスごとに1段（最大5段、`rise`）上がります。高い段の南の縁の下には、2マスの砂岩の岩肌が立ちます。足元は下の段の茂みがかぶさります（BG2 に茂みを描く）。境目が横にまっすぐ続かない所（斜めや狭い所）には岩肌を立てません。階段のように見えてしまうためです。
  - 高い段ほど葉を明るく描きます。高い段の西側の斜面は明るく、東側の斜面は暗くし、高い段のすぐ右と下の低い段に影を落とします。
  - 岩山に面した所（2マス以内）では湖を深いままにし、浅瀬を作りません。浅瀬を歩いて湖の端を回り込めないようにするためです。
- 湖の南岸の湿った土には、粘土の露出を置きます（下の「細部」）。
- 湖の岸には、貝殻・流木・大岩・ヤシの木・蟹を置かず、毎朝の貝殻も打ち上がりません。湖の浅瀬には魚が泳ぎます。高台の層のマスは、枯れ枝・石・蟹・魚・貝殻の数を決める乾いた土地の広さに数えません（`WorldMap::is_high`）。
- **川の流れ出し**: 湖の中には川を通しません。川は、源の真下で湖の水が尽きる岸の1マス上から始まり、口をラッパのように左右へ広げて（`MOUTH_FLARE` 2.2マス）、4マスかけて川幅に絞ります。
  - 口にかかる湖の浅瀬は、川の流れ（渡れない）にします。歩いて口を渡れないようにするためです。
  - 口の流れは湖の青で描き、川の水は口から56pxのあいだ、湖の青と川の色をディザで混ぜて、だんだん川の色に変えます。湖の深い所から浅瀬を挟まずに川へつながって見えます。
  - 口の両岸は湿った土で描きます（海の浜と同じ砂にしない）。

- その下の左の8列は、川の向こうの西の海岸です（後から西へ足した）。西から深い海2列、浅瀬1列、砂浜1〜2列と続き、その東は前からの陸につながります。
  - 北の高台は、西の端で45度の断崖になって下ります（1行に1文字ずつ東へずらしている）。東の端の断崖と同じ向きの崖です。断崖の下は細い森で、その外を浜が北の端まで続きます。
  - 浜の奥、北の断崖の下の `B` が竹林です。竹林は北の 15〜18行の5〜7列（西の草の坂の下）まで続き、坂の上の崖の上（14〜18行の6〜13列、川の西側）の `b` の竹林につながります。
- 左の8列より東は、前の設計図のままです。湖の下の3行が、前からの崖の上の高台です。その下の5行が森で、間に草地の空き地（滝壺の周り）とジャングルの藪がいくつかあります。
- - 24行目の西の海岸のジャングルは、横一列に並べると茂みの壁になって通れなかったので、2つの小さな藪（6〜7列目と11〜12列目）に分けています。川の西側のジャングルは、茂みを生やす割合も約25%に下げています（`WEST_JUNGLE_BUSHES`。ふだんのジャングルは約60%）。西の浜は19〜23行目で1文字ぶん広げています（細いままだとヤシの木が立てられなかったため）。
- その下の12行・9列目から32列目までが、前の最初のエリアと東の海岸です。北の端のジャングルは森に描き直しました。それ以外は前のままです（北にずれたので、行の位置は6行下がっています）。
- 北の崖は東の端（29列目あたり）で向きを変え、南東へ45度で下る断崖になります。断崖と海の間の三角の土地が東の森と海岸で、浜は断崖に沿って細くなって終わります。
- 断崖は右下で、深い海へ突き出した細い岬になります。岬の先の東側にも深い海があり、岬は両側から海に挟まれています。
- 右の8列（後から東へ足した）は、湖の東の岩山から南へ続く尾根です。尾根の西の縁は、15〜27行目で42〜46列目の間をふくらんだりへこんだりさせています（まっすぐな縁だと、マップの端に立つ壁に見えたため）。そのため18〜21行目では、前の松林の42〜43列目の数文字も岩山になっています。尾根は岬の東で海に落ち、岬との間の28〜31行目に浅瀬と深い海の小さな入り江があります。崖の上の東の松林は、ここで東を閉じられます（作っていない東の土地へ、マップの端で突き当たらないようにするため）。

## 特別な場所

手で置く場所です。島を作るときは、その場所の条件を満たすように地形を整えます。今は [`wasm/src/world/island.rs`](../wasm/src/world/island.rs) の定数として持っています。

位置は **最初のエリアのマス** で書いています。マップが北へ（24マスと64マス）、西へ32マス広がる前の座標で、マップ上のマスは x に32、y に88を足したものです。木や岩などの細部も、この座標で乱数を引いて置くので、最初のエリアは広げる前と同じ形のままです。

| 場所 | 位置（最初のエリアのマス） | 内容 |
|---|---|---|
| 漂着地点 | (32, 19) の近く | 主人公が倒れていて目を覚ます場所。この近くで、周りが砂浜で開けた低い浜を探す。周り3マスには木や物を置かない |
| 滝 | 崖の上の湖の南岸（(26.5, -42) の真下の岸）から滝壺まで | 川の源流。湖の南岸からラッパ形の口で流れ出し、崖の上を真っすぐ流れてきて、北の崖を滝になって落ちる（「崖の上の湖と岩山」の「川の流れ出し」） |
| 滝壺 | 中心 (26.5, -6.3)、半径 2.9 | 滝の落ちる丸い淵。周りは森の中の草地 |
| 水汲み場 | 滝壺の東の岸（自動） | 滝壺の南東から順に、岸が草地で崖から離れた所を探す |

## 細部（自動）

木・茂み・ツル植物・花・大岩・流木・貝殻・竹は、高さと地面の種類に合わせて固定のシードで置きます（流木と貝殻は、遊んでいる間に毎朝打ち上がる分もある。[README](README.md#採取) を参照）。森では広葉樹が多くなります。

竹は、ほかの木より先に、竹林の中の草地（崖の上の草地と坂も）に置きます。1本は1マス幅・4マスの高さで、4マスとも竹林の中、川べりでないマスに収まる所にだけ立てます。空いた所の6割ほどに立て、同じ行の左右のすぐ隣には立てません（間を歩いて抜けられる）。形は傾きと高さの違う3種類から選び、左右の向きもばらばらにします。竹林のマスには木（広葉樹・松）・茂み・花を生やしません。蟹・枯れ枝・石・魚・毎朝打ち上がる貝殻の数は、最初のエリアの乾いた土地（砂浜と草地 1531 マス）あたりの数を、島の乾いた土地の広さに合わせて増やします（崖の上は数えません。「島にあるもの」は [README](README.md#島にあるもの) を参照）。

粘土の露出と土の露出（2×2 マス）は、ほかの物をすべて置いたあとで最後に置きます（ほかの物の置き方を変えないため）。

- 粘土の露出（`ClayBed`）は、崖の上の湖の南岸の湿った土に5つ（`CLAY_BEDS`）。ハシゴの列から左右3マス（`LAUNCH_HALF_WIDTH`）は竹筏を出す浜として空け、その外側14マス（`CLAY_REACH`）までに置きます。露出の2×2 マスと周り1マスがすべて湿った土の岸で、何も置かれていない所にだけ置きます（水際の描き分けのマスにかからないように）。露出どうしは左上のマスで3マス以上（`CLAY_SPACING`）離します。描き方は湿った土の上の平らな灰色の粘土で、湿った所が暗く、ところどころに筋状のつやがあり、泥との境目は暗い線です。掘ると、真ん中に奥が影になった穴が開き、底に水がにじみます。
- 土の露出（`BareEarth`）は、草地の広さに合わせて、崖の下の草地に最初のエリアの広さあたり3つ（`EARTH_PATCHES`。今は6つ）、崖の上の高台に2つ（`HIGH_EARTH_PATCHES`。今は2つ）。露出と周り1マスが、何も置かれていない草地（崖の下は草地、崖の上は高台の草地）で、砂浜との境・川べり・崖の足元の埋めた角・湖のそば・空き地として空けておく所でなく、枯れ枝や石が落ちていない所にだけ置きます。露出どうしは14マス以上（`EARTH_SPACING`）離します。描き方は、BG1 の草をはげた形に切り抜き、BG2 に岩のパレットの茶色で乾いた土（まだらな茶色に細かい砂利と小石）を描きます（草のパレットには茶色が1色しかないため）。縁には草が少し残り、上の縁には草の影が落ちます。
- どちらも、形は少し揺らいだ丸で、露出ごとに形が違います。`pnpm map` の「digging」で数を確かめます。

崖の上の高台の草地には、茂みを約15%、花を約5%のマスに置きます（森より多いが、歩ける間を残す）。高台の木（松・広葉樹）から2マス以内のマスの約1.5%にはツル植物が生えます。崖の下の川の西側（各行で川より西）でも、木（広葉樹）から2マス以内か竹のすぐ隣のマスの約5%にツル植物が生えます（`WEST_VINES`）。ヤシの木は、浜の空いた所の約16%に立てますが、川の西の浜では約50%にします（`WEST_PALMS`。浜が細く、立てられる所が少ないため）。枯れ枝と石は、崖の下とは別に、高台の草地の広さ（最初のエリアの乾いた土地の広さあたり）に合わせて、枯れ枝16・石8の割合で置きます（`for_high_area`）。

## 確認ツール

設計図（`island_plan.txt`）や島の作り方（`island.rs`）を変えたら、地図ツールで確かめます。描き変える → 描く → 見る → 直す、を数秒で回せるようにしています。

```bash
pnpm map                          # すべて描く（数秒）
pnpm map --quick                  # 設計の地図だけ
pnpm map --area 55,8,72,22        # 全景をこの範囲のマス（x0,y0,x1,y1）だけ
pnpm map --shrink 2               # 全景を縮めて（2×2 ピクセルを1つに）
pnpm map --bridge                 # 川の狭い所に丸太橋をかけてから描く
pnpm map --wheel                  # 水車小屋の予定地の川に水車を据えてから描く
pnpm map --lathe                  # 水車と、その隣の木工旋盤を据えてから描く
pnpm map --stakes                 # 水車と旋盤を据え、水車小屋の敷地に縄張りの杭を打ってから描く
pnpm map --set-base               # 今の状態を比べる元にする（--clear-base で直前の実行と比べるのに戻す）
pnpm map:watch                    # wasm/src を見張って、変わるたびに描き直す（オプションも渡せる）
```

ツールは `tools` プロファイル（release から LTO を抜いたもの）でビルドするので、描き変えてから数秒で描き直せます。

`wasm/target/map/` に次の画像を書き出します。

| ファイル | 中身 |
|---|---|
| `plan.png` | 設計の地図。1マス6ピクセル（`--scale N` で変えられる）で、地面の種類と木・岩などを色分けして描く。設計図の1文字（4×4マス）の区切りを薄い線、32マスごと（チャンク）を濃い線で引き、上と左にマスの座標を書く。設計図の何文字目かは、マスの座標を4で割ると分かる。特別な場所に印と文字（L 漂着地点、W 水汲み場、F 滝壺、N 川の狭い所、M 水車小屋の予定地、C 低い崖の下、S 西の草の坂のふもと）を付け、下に凡例を付ける。漂着地点から歩いて行けない陸は暗く描く |
| `view.png` | ゲームの見た目の全景。ゲームの描画で画面1枚ずつ描いてつないだもの（HUD・主人公・生き物は描かず、昼の明るさ）。1マス16ピクセルのままで、上と左にマスの座標を書く。`--area x0,y0,x1,y1` でその範囲のマスだけ、`--shrink N` で縮めて描ける（島が大きくなって1枚で扱いにくくなったとき用） |
| `spots.png` | 特別な場所ごとに、その場所を真ん中にしたゲームの画面を並べたもの。場所のマスの四隅に印を付ける |
| `plan-diff.png` | 前と比べて、ゲームの持つマス（地面の種類と、そこにある物）が変わった所。上が前、下が今で、変わっていない所は灰色、変わったマスは色のまま、まとまりごとに赤紫の線で囲む。前になかったマス（島が広がった所）は緑の線で囲み、前の側では空白になる |
| `view-diff.png` | 全景で1ピクセルでも変わったマスを、同じように前と今で並べたもの。絵や描き方を変えたときにも出る。前の全景に入っていなかったマス（島が広がった所や、`--area` で広げた所）は緑の線で囲む |

- **比べる元**: 普段は直前の実行と比べます。`pnpm map --set-base` を付けて描くと、その状態を `wasm/target/map/base/` に取っておき、以後はそれと比べます（いくつも描き変えた合計を見たいとき）。`--clear-base` で直前の実行と比べるのに戻します。変わった所がなければ diff の画像は消え、変わったマスの数と範囲を出力します。
  - 島の大きさが変わったときは、前の島がいちばんよく重なる位置を探して、ずれた分を合わせて比べます（西や北に広げると、前のマスは右や下にずれる）。ずれ・前の大きさ・増えたマスと消えたマスの数を出力します。ずれは、大きさが変わった分の範囲（0 から増えた分まで）で探します。
  - 全景の diff は、前と同じ縮め方で描いたときに、前と今の範囲が重なる所だけを比べます（`--area` を変えても、重なる所は比べる）。ただし、地面や草の細かい模様はマスの位置から決めているので、島が広がって座標がずれると、変えていない所の全景も広く変わったと出ます。全景の diff は島の大きさを変えないときに見てください。
- **島にある数**: 枯れ枝・石・蟹・魚・浜の貝殻の数と、毎朝打ち上がる貝殻の最大数を出力します。崖の下のツル植物の数と乾いた土地のマス数も出します。崖の上の高台の枯れ枝・石・ツル植物の数と、湖（と崖の上の川）の魚の数は、別の行（on the high ground）に出力します。これらは島の乾いた土地の広さで決まるので、島の広さが変わると変わります。[docs/README.md](README.md) の「島」と「採取」に書いた数と合っているかを、これで確かめます。粘土の露出と土の露出の数（崖の下と崖の上）は、別の行（digging）に出力します。
- **行ける範囲**: 漂着地点から歩いて行ける範囲の端、高台に上がれてしまわないか、水汲み場（崖の上のもの（UPPER）はハシゴがないので、滝壺の西の岸のもの（WEST）は丸太橋がないので、OUT OF REACH と出るのが正しい）・低い崖の下・川の狭い所に行けるか（西の草の坂のふもとは、丸太橋がないので OUT OF REACH と出るのが正しい）、川の狭い所で向こう岸に行けないかを出力します（`--bridge` を付けると、川の狭い所に丸太橋をかけてから描き、行ける範囲を調べます。橋の見た目もこれで確かめます）（`--wheel` を付けると、水車小屋の予定地の川に水車を据えてから描きます。水車の見た目はこれで確かめます）（`--lathe` を付けると、水車とその隣の木工旋盤を据えてから描きます。旋盤の見た目はこれで確かめます）（`--stakes` を付けると、さらに水車小屋の敷地に縄張りの杭を打ってから描きます。杭と縄の見た目はこれで確かめます）。設計図を描き変えて、最初のエリアの壁に抜け道ができていないかを確かめるのに使います。高台に上がれないこと、水汲み場と低い崖の下に行けること、川を渡れないこと、低い崖にハシゴを立てると高台に上がれること、川の狭い所に丸太橋をかけると向こう岸へ渡れること、橋を渡ると西の草の坂から崖の上の川の西側へ上がれるが、橋がなければ行けず、ハシゴの側からも行けないこと、ハシゴで上がると湖の浅瀬と崖の上の水汲み場に行けるが、湖の向こう岸へは回り込めないことは、テスト（`pnpm test`）でも確かめます。
- 島はシード1で作ります（ゲームと同じ）。ツールは [`wasm/examples/map.rs`](../wasm/examples/map.rs)、見張りは [`scripts/map-watch.mjs`](../scripts/map-watch.mjs) です。
