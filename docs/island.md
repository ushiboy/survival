# 島の設計

島は毎回同じ形です。大まかな形は手で描いた **設計図** で決め、特別な場所は手で置き、木や石などの細部は固定のシードで自動で置きます。

今のマップは島全体のうちの一部のエリア（南の浜辺）で、これから設計図を描き足して広げていきます（島全体で今の最初のエリアの50倍以上の予定）。

## 設計図

設計図は [`wasm/src/world/island_plan.txt`](../wasm/src/world/island_plan.txt) にある文字の地図です。1文字が 4×4 マスに当たります。行の長さはすべてそろえます。設計図の文字数がそのままマップの広さになります（今は 24×12 文字＝96×48 マス）。

| 文字 | 地面 |
|---|---|
| `~` | 深い海 |
| `-` | 浅瀬 |
| `.` | 砂浜 |
| `,` | 草地 |
| `#` | ジャングル |

- 文字ごとに高さが決まっていて（深い海 -8、浅瀬 -2.5、砂浜 3.5、草地 12、ジャングル 24）、文字と文字の間はなめらかにつなぎます。
- そこへノイズを足して、海岸線やジャングルの縁を自然な曲線にします。升目のカクカクは見えません。沖ではノイズを弱めて、海の真ん中に浅瀬ができないようにしています。
- 浅瀬から沖へは、海底が1マスに高さ1より急に深くならないようにならします。浅瀬と深い海は別のパレットで描くので、急に深くなると境目がマスに沿って四角くなるためです。
- 1文字だけの浅瀬や砂浜は、つなぎ方によっては周りに溶けて消えたり、隣とつながったりします。描いたら下の確認ツールで形を見て調整します。

- 左の16列（64マス）が最初のエリアです。前の自動生成の形をなぞって描き直しました。北にジャングル、その下に草地、広い砂浜、入り江、沖の砂州があります。
- 右の8列（32マス）が東の海岸です。浜が東へ続き、南へ突き出した砂の岬の先に、もう一つ湾があります。

## 特別な場所

手で置く場所です。島を作るときは、その場所の条件を満たすように地形を整えます。今は [`wasm/src/world/island.rs`](../wasm/src/world/island.rs) の定数として持っています。

| 場所 | 位置（マス） | 内容 |
|---|---|---|
| 漂着地点 | (32, 19) の近く | 主人公が倒れていて目を覚ます場所。この近くで、周りが砂浜で開けた低い浜を探す。周り3マスには木や物を置かない |
| 川 | 北の端の外 (27.5, -4) から入り江 (17.9, 29.1) まで | 蛇行する川。渡れない |
| 水汲み場 | 川の上流の草地の岸（自動） | 川に沿って探し、最初に見つかった草地の岸 |

- これから「橋をかけられる場所」「小屋を建てられる広場」などを足していきます。表示では教えず、地形でさりげなく伝えます（「川がここだけ狭い」「森の中に開けた草地がある」など）。

## 細部（自動）

木・茂み・ツル植物・花・大岩・流木・貝殻は、高さと地面の種類に合わせて固定のシードで置きます。蟹・枯れ枝・石・魚・毎朝打ち上がる貝殻の数は、最初のエリア（64×48 マス）の広さあたりの数を島の広さに合わせて増やします（「島にあるもの」は [README](README.md#島にあるもの) を参照）。

## 確認ツール

島全体を1マス数ピクセルの地図にして書き出せます。設計図を描き変えたら、これで形を確かめます。

```bash
cd wasm && cargo run --release --example island_map -- island.ppm 4
```
