# 島の設計

島は毎回同じ形です。大まかな形は手で描いた **設計図** で決め、特別な場所は手で置き、木や石などの細部は固定のシードで自動で置きます。

今のマップは島全体のうちの一部（南の浜辺とその北の森）で、これから設計図を描き足して広げていきます（島全体で最初のエリアの50倍以上の予定）。島の中央には火山を置き、中央へ向かうほど高くなる山道にする予定です。

## 設計図

設計図は [`wasm/src/world/island_plan.txt`](../wasm/src/world/island_plan.txt) にある文字の地図です。1文字が 4×4 マスに当たります。行の長さはすべてそろえます。設計図の文字数がそのままマップの広さになります（今は 36×18 文字＝144×72 マス）。

| 文字 | 地面 |
|---|---|
| `~` | 深い海 |
| `-` | 浅瀬 |
| `.` | 砂浜 |
| `,` | 草地 |
| `T` | 森 |
| `#` | ジャングル（茂みの藪） |
| `^` | 崖の上の高台 |

- 文字ごとに高さが決まっていて（深い海 -8、浅瀬 -2.5、砂浜 3.5、森 11、草地 12、ジャングル 24）、文字と文字の間はなめらかにつなぎます。
- そこへノイズを足して、海岸線やジャングルの縁を自然な曲線にします。升目のカクカクは見えません。沖ではノイズを弱めて、海の真ん中に浅瀬ができないようにしています。
- 浅瀬から沖へは、海底が1マスに高さ1より急に深くならないようにならします。浅瀬と深い海は別のパレットで描くので、急に深くなると境目がマスに沿って四角くなるためです。
- 森は草地と同じ地面で、広葉樹が多く生え、茂みが少しあります。歩いて抜けられます。ジャングルは茂みが密に生えた藪で、ほとんど通れません。
- 1文字だけの浅瀬や砂浜は、つなぎ方によっては周りに溶けて消えたり、隣とつながったりします。描いたら下の確認ツールで形を見て調整します。

### 高台と崖

`^` は、ほかの地面とは別の層です。

- `^` の範囲をなめらかにつなぎ、ノイズで縁を揺らして、高台のマスを決めます。高台は北の端から切れ目なく続くようにし、1マス幅のすき間は埋めます。
- 高台の縁のマスは **崖の縁** です。南へ落ちる所では、縁の下の3マスが **崖の岩肌** になります。東西へ落ちる所は、縁のマスが岩の側面になります。崖の縁と岩肌は通れないので、崖の上へは上がれません。
- 斜めに走る崖は、マスごとに段になります。段の内側の角（上と横が岩肌の地面のマス）は、岩肌の続きで斜めに埋めます。崖の足元が段ではなく斜めの線になり、線は1pxほど揺らいで定規で引いたように見えないようにしています（BG2 に岩のパレットで描き、BG1 の地面をその形に切り抜いて、足元に細い影を落とす）。当たり判定も斜めの線に合わせていて、埋めた岩の側には入れません（主人公の足元が斜めの線で止まる）。埋める角は島を作るときに決めます。波打ち際や川の岸のそば、木や茂みのあるマスは埋めず、埋めたマスには枯れ枝・石・蟹を置きません。
- 高台の下の地面は、`^` のいちばん近く（南を先に見る）に描いた文字の地面が続いていることにします。北の崖の下は森、海に張り出した岬の下は深い海になり、断崖が海に直接落ちます。
- 崖を斜めに走らせるときは、`^` の縁を1行に1文字ずつずらします（45度）。それより急な斜め（2行に1文字など）にすると、南向きの岩肌がとぎれとぎれになり、崖がつながって見えません。
- 高台の上には茂みと広葉樹を密に置きます（今は行けない場所です）。

```
##TTTTTTTTTTT,,TTTTTTT,,T^^^^^^^^^^^

-~~~~~~~~~~.~~~~~-..-~~~~~--....^^^^

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~^~

```

- 上の3行が崖の上の高台です。その下の5行が森で、間に草地の空き地（滝壺の周り）とジャングルの藪がいくつかあります。
- その下の12行・左の24列が、前の最初のエリアと東の海岸です。北の端のジャングルは森に描き直しました。それ以外は前のままです（北にずれたので、行の位置は6行下がっています）。
- 北の崖は東の端（21列目あたり）で向きを変え、南東へ45度で下る断崖になります。断崖と海の間の三角の土地が東の森と海岸で、浜は断崖に沿って細くなって終わります。
- 断崖は右下で、深い海へ突き出した細い岬になります。岬の先の東側にも深い海があり、岬は両側から海に挟まれています。

## 特別な場所

手で置く場所です。島を作るときは、その場所の条件を満たすように地形を整えます。今は [`wasm/src/world/island.rs`](../wasm/src/world/island.rs) の定数として持っています。

位置は **最初のエリアのマス** で書いています。マップが北へ24マス広がる前の座標で、マップ上のマスは y に24を足したものです。木や岩などの細部も、この座標で乱数を引いて置くので、最初のエリアは広げる前と同じ形のままです。

| 場所 | 位置（最初のエリアのマス） | 内容 |
|---|---|---|
| 漂着地点 | (32, 19) の近く | 主人公が倒れていて目を覚ます場所。この近くで、周りが砂浜で開けた低い浜を探す。周り3マスには木や物を置かない |
| 滝 | 崖の上 (26.5, -30) から滝壺まで | 川の源流。崖の上から真っすぐ流れてきて、北の崖を滝になって落ちる |
| 滝壺 | 中心 (26.5, -6.3)、半径 2.9 | 滝の落ちる丸い淵。周りは森の中の草地 |
| 水汲み場 | 滝壺の岸（自動） | 滝壺の南東から順に、岸が草地で崖から離れた所を探す |
| 川 | 森の (27.5, -4) から入り江 (17.9, 29.1) まで | 滝壺から出た流れが広がって、蛇行する川になる。渡れない |
| 川の狭い所 | (22, 12) の近く | 川幅がここだけ細くなっている（半分の幅 0.7 マス、ふだんは 1.1〜1.6）。橋をかける場所の予定 |
| 河口の流れ | 河口から沖の深い海まで（最大16マス） | 川の流れが海へ続いている。海に入った所から沖へ向かって左右に末広がりになり（初めはゆっくり、沖ほど速く広がる）、幅いっぱいが深い海に届くまで続いて、深い海に溶け込む。浅瀬の中でも深い海と同じ濃い色で描き（BG2 に描き、BG1 の浅瀬を流れの形に切り抜く）、川の色の筋が沖へ流れて、深い海の上では消えていく。流れが少しでもかかるマスは通れないので、川の向こうへ回り込めない |
| 崖の上の松と松ぼっくり | くぼみの真ん中の1マス右、崖の縁の1行後ろに松の根元 | 崖の上に何があるかを下から見せる目印。松は3×4マスで、ほかの木より先に置き、広葉樹はその周りを空ける。松の下の高台に松ぼっくりを3つ（くぼみの左上に2つ、右に1つ）置く。崖の下には、くぼみの真ん中の足元（ハシゴの足元のマス）に1つだけ置く。崩れた縁から転がり落ちてきた形で、拾うと主人公が見上げて辺りを見渡す（[松ぼっくり](items/pine-cone.md)） |
| 低い崖（崖のくぼみ） | マップの x 62〜64 の北の崖 | 岩肌が2マスしかない所（ふだんは3マス）。この3マスだけ崖の縁が1行下がっていて、足元は左右の崖とまっすぐにそろう。下げた縁のマスは隣の崖の一番上の段と同じ石組みで描くので、崖の上の一部が崩れて低くなったように見える。崖の上の草が、縁から下へ台形（底の平らな `\___/` の形）に13pxほど沈み込んでいる。台形の平らな底は3マスの両端から半マスずつ内側までで、斜めの辺は左右の高い崖のマスへ半マス入り込むところから始まる（斜めの幅は16px）。くぼみの上では縁の暗い張り出し線を途切れさせ、草が下り坂になって手前ほど暗くなり、手前の暗い縁から岩肌に落ちる。台形の斜めの両端では、草の縁・岩肌の影・縁の張り出しを薄くして、左右の縁の線に濃い影がつながらないようにしている。斜めの両端には、くぼみより高い左右の地面の側面が細い岩の帯として見える（光は左上からなので、左の側面は濃い影で、その右の草にも幅12pxほどの影を落とす（側面に近いほど濃く、離れるほど薄い）。台形の左の肩では、縁の暗い張り出しを草に置き換えず、影のまま残す。右の側面は明るい）。岩の帯は、縁のすぐ下では周りの岩と同じ影の色にして、縁の線より上に飛び出さないようにしている。これで地面が下がっていると読める。縁の下からは木の根が少し垂れ下がる（沈んだ草は BG2 に草のパレットで描き、岩肌をその形に切り抜く。根は岩のパレットの木の色）。むき出しの土や、縁の線をまっすぐ通した影は入れない（土は草の上に浮いた帯に、まっすぐな影は草が線から突き出したように見えたため）。足元は斜めに切らない（上下が同じ台形になって似て見えたため）。真ん中の x 63 だけに[ハシゴ](items/ladder.md)をかけられる。立てかけるとハシゴの先が縁より上に出て、崖の上へ登れる。くぼみの左右3マスは崖の縁をまっすぐにして、くぼみが周りの岩から浮かないようにしている。くぼみの前の森は半径3.7マスの空き地で、木・茂み・花を置かない（広すぎるとがらんとして見えたため） |

- 表示では教えず、地形でさりげなく伝えます（「川がここだけ狭い」「崖がここだけ低く、くぼんでいて、前が開けている」など）。これから「小屋を建てられる広場」などを足していきます。

## 細部（自動）

木・茂み・ツル植物・花・大岩・流木・貝殻は、高さと地面の種類に合わせて固定のシードで置きます。森では広葉樹が多くなります。蟹・枯れ枝・石・魚・毎朝打ち上がる貝殻の数は、最初のエリアの乾いた土地（砂浜と草地 1531 マス）あたりの数を、島の乾いた土地の広さに合わせて増やします（崖の上は数えません。「島にあるもの」は [README](README.md#島にあるもの) を参照）。

## 確認ツール

島全体を1マス数ピクセルの地図にして書き出せます。設計図を描き変えたら、これで形を確かめます。

```bash
cd wasm && cargo run --release --example island_map -- island.ppm 4
```

- 漂着地点から歩いて行ける所を調べて、行けない陸を暗く描きます。
- 行ける範囲の端、高台に上がれてしまわないか、水汲み場・低い崖の下・川の狭い所の手前の岸に行けるか、向こう岸に行けないかを出力します。設計図を描き変えて、最初のエリアの壁に抜け道ができていないかを確かめるのに使います。高台に上がれないこと、水汲み場と低い崖の下に行けること、川を渡れないこと、低い崖にハシゴを立てると高台に上がれることは、テスト（`pnpm test`）でも確かめます。
