# 描画（SFC Mode 1 の制約）

見た目と描画は、スーパーファミコン（Mode 1）の制約に合わせています（[設計の方針](README.md#sfc-らしさ)）。描画は Rust 側のソフトウェア PPU（`wasm/src/ppu/`）で行い、ワールドから PPU への入力は `wasm/src/render/` が作ります。

## 画面と色

- 256×224、15bit カラー、CGRAM 256色（BG 4bpp 16色×8 / OBJ 16色×8）。
- BG3（2bpp）は CGRAM 先頭32色を共有するため、地形は BG パレット 2〜7 を使います。

## BG とスプライト

- BG1: 地面、BG2: ヤシの葉など頭上オブジェ（優先度 High でスプライトより手前）、BG3: HUD。
- 16×16 タイル単位でパレット・左右反転・優先度を持ちます。
- スプライトは最大128枚、1ライン32枚／34スライバー。
- 据えた[狼煙台](items/signal-fire.md)は BG ではなくスプライト（32×32 1枚）で描きます。置いたマスの BG1 は、何もないときと同じ地面のままです（どの地面にも置けるので、地面ごとのタイルを作らずに済む）。マスは置物（`Feature::SignalFire`）として持ちますが、焚き火と同じく通り抜けられます。
- 水車小屋の骨組みの柱は、BG ではなくスプライト（8×24 と 8×40 の2種類、6本）で描きます。主人公と足元の高さで並べ替えるので、柱の奥と手前のどちらに立っても重なりが正しくなります（BG の2枚の層では、どちらか一方しか正しく描けないため）。柱の頭を結ぶ桁は、頭より高い所にあるので BG2（優先度 High）に、柱の立つ礎石は BG1 に描きます。桁をつなぐ梁3本は、優先度3のスプライト（8×64）で、どのスプライトよりも手前に描きます。壁のすぐ手前で BG2 より手前に出した主人公よりも、さらに手前に出すためです。壁ができると、南の柱3本は南の壁の面（BG2）に隠れるので描かず、礎石も描きません。
- 水車小屋の屋根（茅葺きの切妻）は、敷地の1行北から南の縁の1行北まで、BG2（優先度 High）に描きます。中にいる主人公は屋根に隠れます（中では BG2 より手前に出さず、影のスプライトも描きません）。屋根の下の柱と梁のスプライトは描きません。屋根を作っている間も、作業を始めた時から屋根を描き（柱と梁も描かない）、屋根の上で作業する主人公は優先度 3 にして屋根の手前に出します。棟の上の押さえの棒も敷地の1行北のマスに収め、北東で川の水を描く BG2 と重ならないようにしています。
- 水車小屋の中の部屋は、別のマップに切り替えるのではなく、同じマップの島の南に足した行（島のカメラの範囲の外）に置いてあります（SFC のゲームで屋内をマップの見えない所に置くのと同じ）。中にいるあいだは、カメラを部屋の範囲に収め、背景色（CGRAM の0番）を黒にして、部屋の外の透明なタイルを黒く見せます。部屋は BG1 だけで描きます（壁の面も、主人公より奥にあるので BG2 に分けなくてよい）。床・壁・作業台・旋盤と、作業台で作った棚・寝床は草のパレットで描き、床は網点（4×4 のディザ）で外の土より暗く見せます。棚には、預けた量によらずいつも同じ物（中の段に竹と椰子の実、下の段に丸太と葉の束。上の段は屋根の縁に近く、載せた物が切れるので空けておく）を描きます。棚は北の壁に沿って床から壁の面の上のほうまで伸びるので、壁の面のマス（BG1）にも棚を描き重ねます（主人公は壁の前に立てないので、BG2 に分けなくてよい）。寝床で眠る主人公は、仰向けの姿のスプライト（24×32。立ち姿の正面を目を閉じて描いたもの）を寝床の上に出します。囲炉裏は、石と灰の灰色が草のパレットにないので、囲炉裏の4マスだけ岩のパレット（`PAL_ROCK`）で描きます（`hearth_tile`）。まわりの床は、岩のパレットにある近い色（砂の3色と、土の色の代わりに木の色）で描き直してつなげます。囲炉裏の炎は焚き火と同じ炎のスプライト（燃え尽きる前の2時間は小さい炎）を炉の真ん中に出します。灯明は、壁から突き出して床より上にあるので BG ではなくスプライト（16×16。灯っている炎の3コマと、灯っていない形）で描き、主人公と足元の高さで並べます（灯明のマスは通れないので、北に立てば灯明が手前、南に立てば主人公が手前）。棚の画面の棚板は、BG3 の1枚のタイル（`shelf_board`）を横に並べ、HUD の橙のパレットで描きます。戸を通るときの暗転は、画面の明るさ（INIDISP の明るさ）を10フレームで下げて上げ、暗いあいだに主人公とカメラを移します。
- 水車小屋の戸は、南の壁の面と同じく、戸口の行の分を BG1 に、その1行北の分を BG2 に描きます。戸が1段動くたびに、戸口の2マスとその1行北の2マスのタイルを描き直します（VRAM のタイルを書き換えるアニメーション。スプライトにしないのは、壁に引き込まれて隠れる所を切り取れないため）。
- 水車小屋の壁の面は、壁の立つ行（北の縁・南の縁）の分を BG1 に、それより上の行の分を BG2 に描きます。面の奥（北の壁の外、南の壁の内側）に立つ主人公は隠れ、手前に立てば手前に出ます。面のすぐ手前（南の壁の南の外、北の壁の内側のすぐ南）では頭が BG2 の面の行に届くので、木の葉の手前と同じく主人公を優先度3にして BG2 より手前に出します。壁に隠れた足元には、主人公の影（スプライト）を描きません（影は最後に積まれるので、BG2 の上に出てしまうため）。
- 狼煙の煙は、16×16 と 32×32 の煙の玉のスプライト12枚を、時間で昇らせて描きます（`entity/signal_fire.rs`。乱数を使わないので、何台燃えていても同じ計算）。木の葉より手前（優先度3）に出します。

## 救助の場面

- 救助の場面の3つのカット（[狼煙](README.md#狼煙)）は、絵をフルカラーで描いてから（`assets/ending_art.rs`）、SFC で出せる形に合わせます（`render/scene.rs`）。カートリッジ用に変換する工程を、ゲームの中で行う形です。
  - 背景（256×128）は BG1 の 16×16 ブロック 16×8 枚にし、各ブロックを BG パレット2〜7（6本、各15色）のどれか1本で描きます（0〜1 は HUD と共有なので使わない）。パレットは、ブロックを色でまとめて median cut で15色を選び、各ブロックが一番よく描けるパレットを選び直す、を数回くり返して決めます。
  - カットはそれぞれ、最初に見せるときに作って VRAM に載せ、次のカットのときに外します（暗転の間に VRAM へ転送する想定）。1カットは 128 ブロック（16 KiB）です。
  - 3つ目のカットの小型機はスプライトです（64×64 を2枚。スプライトパレット1の15色）。止まっていますが、背景とは別のパレットで描けるので、背景に描き込むより色がきれいに出ます。
  - 場面の帯は、BG1 のスクロールで画面の上下中央に置き、帯の外は背景色（黒）です。

## カラー演算と夜の明かり

- 昼はスプライトパレット4〜7（影・波紋・水中の脚・狼煙の煙）をサブ画面と半透明合成します。狼煙の煙の灰色は、波紋と同じパレット5（`OBJ_WATER_FX`）の空いていた色に入れています。魚油を注いだ狼煙の黒い煙は、影のパレット4（`OBJ_SHADOW`）の、白い煙と同じ番号（4〜6）に暗い色を入れ、同じ煙のスプライトをパレット4で描きます（半透明なのは白い煙と同じ）。
- 夜はサブ画面を減算して暗闇にします（HUD とパレット0〜3のスプライト＝主人公は対象外）。
- 水車小屋の中で灯明が灯っているとき（夕方に暗くなり始めてから）は、時間帯の色の代わりに、昼の色に少し暖かい色を掛けたもの（`Lighting::LAMPLIT`）で CGRAM を作り、夜の減算もしません。
- 夜の明かり（持ち歩いている松明と、すべての焚き火、水車小屋の燃えている囲炉裏）:
  - 放射状の光マスク（2bpp・4段階＋ディザ、16×16タイル）を、BG3 マップの画面外にある画面サイズの「光の地図」へ光源ごとに毎フレーム並べます（ワールドの 8px グリッドに揃える）。
  - 光が重なるセルは、明るい方を取ったタイルを予備タイル（最大96枚）へ書き込みます（ブランク中の VRAM 転送相当）。
  - HDMA で HUD より下のラインの BG3 をメイン画面→サブ画面に切り替え、カメラの端数だけスクロールして光の地図を重ねます。
  - 光の外は固定色＝完全な暗闇を減算します。マスクの色を毎フレーム少し揺らして炎のちらつきにします。
- 時間帯は CGRAM を毎フレーム再計算します（パレット DMA 相当）。水面はパレットサイクル、波打ち際はタイル差し替えのアニメです。

## VRAM とストリーミング

- 「現在画面に必要なタイル量」を表示のダイアログに出します（64 KiB 以内）。
- 地面のタイルは 32×32 マスの区画単位でストリーミングします（`render/tileset.rs`）。
  - 画面付近の区画だけを作り、離れた区画のタイルは捨てます。
  - タイルは使っているセルの数を数え、どのセルも使わなくなったものは VRAM から解放してスロットを再利用します（スクロールに合わせた CHR 転送相当）。
  - 確かめるツールは `stream_check`（リポジトリ直下の [README](../README.md#development-tools)）。
- 蟹・魚・落ちたアイテムは、画面付近の起きている区画でだけ動かします（`game/regions.rs`。[区画（チャンク）](README.md#区画チャンク)）。眠っていた区画が起きるとき、眠っていた時間を受け取ります。
