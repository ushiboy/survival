# 椰子の実（COCONUT）

| 項目 | 内容 |
|---|---|
| 種類 | 食べ物 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Coconut` |

ゲーム内の説明文:

> A WHOLE COCONUT IN ITS HUSK. HARD TO GET INTO.

## 手に入れ方

- ヤシの木を A で揺する。3〜5回揺するごとに1つ落ちる（1本に3つまで、戻らない）
- ヤシの木を切り倒すと、残っていた実も落ちる

## 使い道

- 石器ナイフを持って割ると[割った椰子の実](opened-coconut.md)になる（レシピ: [割った椰子の実](../recipes/opened-coconut.md)）

## メモ

- そのままでは食べられない。素手で割るのは現実的でないので、ナイフが必要
