# 枯れ枝（BRANCH）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Branch` |

ゲーム内の説明文:

> A DEAD BRANCH, GOOD FOR TOOLS AND FIRES.

## 手に入れ方

- 地面に落ちているものを拾う（今のエリアに16本。主に草地。戻らない）

## 使い道

- 焚き火の燃料（火起こし器で1本使う）
- レシピの材料: [石斧](../recipes/stone-axe.md)、[木の槍](../recipes/wood-spear.md)、[松明](../recipes/torch.md)、[シェルター](../recipes/shelter.md)、[背負子](../recipes/pack-frame.md)、[火起こし器](../recipes/fire-drill.md)

## メモ

- 今は数に限りがある。多くのレシピで取り合いになる
