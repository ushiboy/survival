# 枯れ枝（BRANCH）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Branch` |

ゲーム内の説明文:

> A DEAD BRANCH, GOOD FOR TOOLS AND FIRES.

## 手に入れ方

- 地面に落ちているものを拾う（崖の下に46本。主に草地。崖の上の高台にも60本。戻らない）
- 砂浜の流木を[石斧](stone-axe.md)で2回叩いて割ると、2〜3本落ちる。割った流木は消えるが、西の海岸（川の向こう）の浜には、ときどき新しい流木が打ち上がる（毎朝1/3の確率で1本、西の海岸に3本あるまで）。最初のエリア側の浜の流木は戻らない

## 使い道

- 焚き火の燃料（火起こし器で1本使う。[松ぼっくり](pine-cone.md)を持っていれば、そちらが先に使われる）
- レシピの材料: [石斧](../recipes/stone-axe.md)、[木の槍](../recipes/wood-spear.md)、[松明](../recipes/torch.md)、[シェルター](../recipes/shelter.md)、[背負子](../recipes/pack-frame.md)、[火起こし器](../recipes/fire-drill.md)、[釣り竿](../recipes/fishing-rod.md)、[ハシゴ](../recipes/ladder.md)

## メモ

- 落ちている枝には限りがあり、多くのレシピで取り合いになる。流木を割れば増やせる。西の海岸に渡れば、打ち上がる流木から少しずつ取り続けられる（1日あたり平均で約0.8本。毎日焚き火をつけ続けるには少し足りない量）
- 流木は独立したアイテムにはせず、枯れ枝の入手元にしている（流木と枯れ枝の使い分けがはっきりしないため）
