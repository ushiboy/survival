# シェルター（SHELTER）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（持っているだけで使う） |
| バッグでの大きさ | 2×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Shelter` |

ゲーム内の説明文:

> A LEAN-TO, ROLLED UP. SLEEP UNDER IT TO HEAL FASTER AND TIRE LESS.

## 手に入れ方

- レシピ: [シェルター](../recipes/shelter.md)

## 使い道

- バッグに入れて眠ると、その場にシェルターを張って中で眠る
- 体力の戻りが10分で1になる（ない場合は15分で1。どちらも最大64の64分の1あたり）
- 空腹の減りが起きているときの12分の1（ない場合は6分の1）、渇きの減りが3分の1（ない場合は2分の1）になる

## メモ

- 眠っている間は主人公が見えなくなり、シェルターから Zzz が出る
