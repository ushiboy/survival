# 茅葺き（THATCH）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 2×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Thatch` |

ゲーム内の説明文:

> PALM FRONDS WOVEN WITH VINE INTO A PIECE OF ROOF.

## 手に入れ方

- レシピ: [茅葺き](../recipes/thatch.md)

## 使い道

- レシピの材料: [シェルター](../recipes/shelter.md)（2つ）
- 水車小屋の屋根の材料（×6。軒から棟へ段々に重ねて縛る）: メインドキュメントの「[水車小屋](../README.md#水車小屋)」
