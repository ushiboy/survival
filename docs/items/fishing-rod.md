# 釣り竿（FISHING ROD）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×3 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::FishingRod` |

ゲーム内の説明文:

> A ROD WITH A ROPE LINE AND A SHELL HOOK. CAST IT INTO WATER WHERE FISH SWIM.

## 手に入れ方

- レシピ: [釣り竿](../recipes/fishing-rod.md)

## 使い道

- 手に持って、水に向かって B を押すと糸を投げる。釣り方はメインドキュメントの「釣り」を参照
- 釣れたものは[魚](fish.md)になる

## メモ

- 糸は、魚が掛かったときの力に耐えるよう、ツルではなくロープにしている
- 浅瀬に入っている間は投げられない（ほかの道具と同じ）
- 投げた先が水でないときは、B を押しても何も起きない
