# ラワン材（LAUAN TIMBER）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 2×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::LauanTimber` |

ゲーム内の説明文:

> A SQUARED LENGTH OF LAUAN, A STRONG HARDWOOD.

## 手に入れ方

- 広葉樹を[石斧](stone-axe.md)で切り倒す（5回叩く。1本で3つ）。先に樹皮を剥いでいても数は変わらない。まだ剥いでいない[樹皮](bark.md)も一緒に落ちる

## 使い道

- 今は使い道なし（硬い木材として使う予定）
