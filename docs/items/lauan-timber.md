# ラワン材（LAUAN TIMBER）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 2×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::LauanTimber` |

ゲーム内の説明文:

> A SQUARED LENGTH OF LAUAN, A LIGHT TROPICAL HARDWOOD.

## 手に入れ方

- 広葉樹を[石斧](stone-axe.md)で切り倒す（5回叩く。1本で3つ）。先に樹皮を剥いでいても数は変わらない。まだ剥いでいない[樹皮](bark.md)も一緒に落ちる

## 使い道

- レシピの材料: [ハシゴ](../recipes/ladder.md)、[水車](../recipes/water-wheel.md)（軸・腕・輪と、支えの柱）、[木工旋盤](../recipes/wood-lathe.md)（台と主軸台・心押し台）、[スポーク車輪](../recipes/spoked-wheel.md)（こしきと輪）、[リアカー](../recipes/handcart.md)（荷台と車軸）
- 水車小屋の骨組みの材料（×8。柱と桁）と、屋根と戸の段階の材料（×2。戸板と敷居）: メインドキュメントの「[水車小屋](../README.md#水車小屋)」
- 水車小屋の作業台で作る設備の材料: 棚（×2。柱と脚）、寝床（×2。枠と脚）。メインドキュメントの「[小屋を整える](../README.md#小屋を整えるfit-out)」
