# 貝の釣り針（SHELL HOOK）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::ShellHook` |

ゲーム内の説明文:

> A HOOK GROUND OUT OF SHELL. SMALL BUT SHARP.

## 手に入れ方

- レシピ: [貝の釣り針](../recipes/shell-hook.md)（[貝殻](sea-shell.md)を[石器ナイフ](stone-knife.md)で削る）

## 使い道

- レシピの材料: [釣り竿](../recipes/fishing-rod.md)

## メモ

- 釣り竿の一部になり、釣りで使っても減らない（魚に持っていかれることはない）
