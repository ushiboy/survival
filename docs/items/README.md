# アイテム

島で手に入る素材・道具・食べ物の一覧です。1つずつ別ファイルにまとめています。

新しいアイテムを足すときは、このディレクトリにファイルを追加し、この一覧にも行を足してください。

- 大きさはバッグのマス数（横×縦）です。回して入れると縦横が入れ替わります。
- 「持っているだけで使う」道具は、手に持たなくてもバッグに入っていれば効果があります。
- 木材（木材・ラワン材・パイン材）は、どれも 2×2 マスで重ねられません（スポーク車輪も 2×2 で重ねられません）。竹は木ではないので別で、1×3 マスで5本まで重ねられます。
- 松明だけは特例で、バッグに入らず、作ってから燃え尽きるまで主人公が持ち歩きます。
