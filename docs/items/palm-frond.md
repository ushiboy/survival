# ヤシの葉（PALM FROND）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 5 |
| コード | `ItemKind::PalmFrond` |

ゲーム内の説明文:

> A LONG PALM LEAF. WOVEN TOGETHER, FRONDS KEEP OFF RAIN.

## 手に入れ方

- ヤシの木を揺すると、1回につき15%で落ちる（実のないヤシでも落ちる）
- ヤシの木を切り倒すと3枚落ちる

## 使い道

- レシピの材料: [茅葺き](../recipes/thatch.md)（4枚）
