# ヤシの葉（PALM FROND）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 5 |
| コード | `ItemKind::PalmFrond` |

ゲーム内の説明文:

> A LONG PALM LEAF. WOVEN TOGETHER, FRONDS KEEP OFF RAIN.

## 手に入れ方

- ヤシの木を揺すると、1回につき15%で落ちる（実のないヤシでも落ちる）
- ヤシの木を切り倒すと3枚落ちる

## 使い道

- レシピの材料: [茅葺き](../recipes/thatch.md)（4枚）
- [狼煙台](signal-fire.md)で燃やして煙を上げる（火を付けるたびに1枚。1日に1枚あれば毎日煙を上げられる）

## メモ

- 茅葺き（シェルターの屋根、水車小屋の屋根）と狼煙で取り合いになる（水車小屋の屋根の茅葺き6枚には、ヤシの葉が24枚要る）。揺すれば何度でも落ちる（1回あたり15%）ので尽きることはないが、毎日狼煙を上げ続けるには、毎日ヤシを揺することになる
