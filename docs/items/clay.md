# 粘土（CLAY）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 3 |
| コード | `ItemKind::Clay` |

ゲーム内の説明文:

> WET, STICKY CLAY. IT CAN BE SHAPED, AND HARDENS IN A FIRE.

## 手に入れ方

- 崖の上の湖の南岸にある粘土の露出（5か所）を、[竹のスコップ](bamboo-spade.md)で掘る。1回で2つ。1か所につき1日1回で、翌朝に戻る

## 使い道

- 水車小屋の壁の材料（×6。土と練り混ぜて塗る土壁）: メインドキュメントの「[水車小屋](../README.md#水車小屋)」
- 土器・土のかまど・レンガにも使う予定（メインドキュメントの「まだコードにないコンセプト」）

## メモ

- 重くかさばるので、重ねられるのは3つまで（竹の5本より少ない）。数が要る物を作るには、何度も通うか背負子が要る
- 粘土の露出は、ハシゴの真北の浜（竹筏を出す浜）を空けて、その両脇に並ぶ
- バッグの絵は、灰青色の小さな塊を山盛りにした形（石と見分けやすいように、1つの丸い塊にはしない）。地面に落ちた絵も小さな山
