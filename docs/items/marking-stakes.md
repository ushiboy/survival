# 縄張りの杭（MARKING STAKES）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×3 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::MarkingStakes` |

ゲーム内の説明文:

> STAKES AND A LINE TO MARK OUT GROUND FOR SOMETHING BIG.

## 手に入れ方

- レシピ: [縄張りの杭](../recipes/marking-stakes.md)

## 使い道

- 手に持って、据えた[木工旋盤](wood-lathe.md)の近くで B を押すと、水車小屋を建てる土地（水車小屋の敷地）を杭と縄で区切る（縄張り）。杭はバッグから消えて、その場に残る
  - 敷地は決まっている: 水車小屋の予定地の岸から西へ6マス、北へ3マス・南へ2マスの 7×6 マス（今のマップでは x 51〜57、y 85〜90。`mill_plot`）。東の端に旋盤が入り、北東の水汲み場にはかからない（[島の設計](../island.md#特別な場所)の「水車小屋の予定地」）
  - B を押す所は、敷地から縦横4マス以内（`STAKES_REACH`）ならどこでもよく、向きも問わない。主人公は、敷地の真ん中（予定地の岸から西へ3マス。`stakes_stand`）まで自分で歩いて（横、縦の順に、遠いほうから）、下を向いてから杭を打つ。途中で何かにぶつかったり、時間がかかりすぎたり（240フレーム）したら打たない
  - 敷地の四隅に杭が立ち、そのあいだの縁に縄が張られる。杭は通れないが、縄は地面に張ってあるだけで、またいで通れる。東の縁の縄は、旋盤の上を通って途切れずに続く
  - 杭と一緒に、敷地の西のすぐ外に普請台が立つ（向かって A で、小屋を建てる BUILD の画面が開く。[README](../README.md#水車小屋) の「水車小屋」）
  - 主人公が隅の杭のマスに立っていたときは、一番近い空いた所へ押し出される
  - 旋盤をまだ据えていないとき、もう縄張りをしたあと、敷地の隅に何かがあるとき、ほかの所では、B を押しても何も起きない
- 旋盤を据えたあと、杭を持たずに敷地から縦横4マス以内で A を押すと、主人公が考える仕草をする（ここで何かできそうだというヒント）。向きは問わない。縄張りをした後は出ない。リアカーを引いているときや、置いたリアカーに向かっているときは、A はリアカーのほうに使われ、考える仕草はしない。水汲み場で水を汲むほうも先になる
- [道具帯](tool-belt.md)には提げられない（道具ではなく、打てばなくなる材料の束なので）

## メモ

- 竹を石器ナイフで割って尖らせた杭と、杭のあいだに張るロープの束。建てる前に、杭と縄で建物の場所と大きさを地面に示す（現実の地縄張りと同じ）
- 縄張りは水車小屋を建てる最初の一歩。このあと、敷地に材料を運び込んで段階的に建てる（[README](../README.md#水車小屋) の「水車小屋」）。土台ができると、杭と縄はなくなる（普請台は残る）
- 一度打ったら抜けない。打ったことはセーブに入る（置物の差分）
- 縄張りをした見た目は `pnpm map --stakes` で描ける（[島の設計](../island.md#確認ツール)）
- バッグの絵は、割った竹の杭3本を並べて、真ん中をロープの束で巻いた形（緑の皮と白い内側が見える）。地面に落ちた絵は、それを横に寝かせた形
