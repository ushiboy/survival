# 石斧（STONE AXE）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::StoneAxe` |

ゲーム内の説明文:

> A SHARP STONE LASHED TO A BRANCH. FELLS TREES.

## 手に入れ方

- レシピ: [石斧](../recipes/stone-axe.md)

## 使い道

- 手に持って B で振る
- ヤシの木を3回、広葉樹を5回叩くと切り倒せる（広葉樹からは、ラワン材と、まだ剥いでいない樹皮が落ちる）
- 砂浜の流木を2回叩くと割れて、[枯れ枝](branch.md)が2〜3本になる
- 大岩・切り株を叩くと弾かれる。茂みやツル植物を叩くと葉が散るだけ
- レシピの道具: [ハシゴ](../recipes/ladder.md)（柱を削りそろえる）

## メモ

- 丈夫さが要るので、ツルではなくロープで縛る
