# 石斧（STONE AXE）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::StoneAxe` |

ゲーム内の説明文:

> A SHARP STONE LASHED TO A BRANCH. FELLS TREES.

## 手に入れ方

- レシピ: [石斧](../recipes/stone-axe.md)

## 使い道

- 手に持って B で振る
- ヤシの木を3回、崖の上の松を4回、広葉樹を5回叩くと切り倒せる（松からは[パイン材](pine-timber.md)と残っていた松ぼっくり、広葉樹からはラワン材と、まだ剥いでいない樹皮が落ちる）
- 西の竹林の竹を2回叩くと切り倒せる（[竹](bamboo.md)が1本落ちる）
- 砂浜の流木を2回叩くと割れて、[枯れ枝](branch.md)が2〜3本になる（西の海岸の浜には、流木がときどき新しく打ち上がる）
- 大岩・切り株（竹の切り株も）を叩くと弾かれる。茂みやツル植物を叩くと葉が散るだけ
- レシピの道具: [ハシゴ](../recipes/ladder.md)（柱を削りそろえる）、[丸太橋](../recipes/log-bridge.md)（丸太の両端を削りそろえる）、[水車](../recipes/water-wheel.md)（ラワン材を削って軸・腕・輪と支えの柱にする）

## メモ

- 丈夫さが要るので、ツルではなくロープで縛る
