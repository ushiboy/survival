# 石斧（STONE AXE）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::StoneAxe` |

ゲーム内の説明文:

> A SHARP STONE LASHED TO A BRANCH. FELLS TREES.

## 手に入れ方

- レシピ: [石斧](../recipes/stone-axe.md)

## 使い道

- 手に持って B で振る
- ヤシの木を3回、広葉樹を5回叩くと切り倒せる
- 大岩・流木・切り株を叩くと弾かれる。茂みやツル植物を叩くと葉が散るだけ

## メモ

- 丈夫さが要るので、ツルではなくロープで縛る
