# 蟹（CRAB）

| 項目 | 内容 |
|---|---|
| 種類 | 食べ物 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Crab` |

ゲーム内の説明文:

> A RAW CRAB. FILLING, BUT BETTER COOKED.

## 手に入れ方

- [木の槍](wood-spear.md)で突いて捕まえる（今のエリアに10匹。戻らない）

## 使い道

- EAT で生のまま食べる。満腹度 +30、水分 +2
- 焚き火で焼くと[焼き蟹](grilled-crab.md)になる（レシピ: [焼き蟹](../recipes/grilled-crab.md)）
