# 土（SOIL）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 3 |
| コード | `ItemKind::Soil` |

ゲーム内の説明文:

> A HANDFUL OF EARTH.

## 手に入れ方

- 草地の土の露出（草がはげて土がむき出しになった所）を、[掘り棒](digging-stick.md)で掘る。1回で1つ。何度でも掘れる
- 土の露出は、崖の下の草地に6か所（最初のエリアにも西の海岸にもある）、崖の上の高台に2か所ある

## 使い道

- レシピの材料: [狼煙台](../recipes/signal-fire.md)（石を据える土台）
- 水車小屋の土台の材料（×4。突き固めて礎石を据える）: メインドキュメントの「[水車小屋](../README.md#水車小屋)」
- 土のかまどなどにも使う予定（メインドキュメントの「まだコードにないコンセプト」）

## メモ

- どこにでもある物なので、掘れる回数に制限はない。運べる量はバッグの広さで決まる
- 重いので、重ねられるのは3つまで
- バッグの絵は、茶色の土を山盛りにした形（石と見分けやすいように、1つの丸い塊にはしない）。地面に落ちた絵も小さな山
