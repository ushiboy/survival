# 竹（BAMBOO）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×3 マス |
| 重ねられる数 | 5 |
| コード | `ItemKind::Bamboo` |

ゲーム内の説明文:

> A LENGTH OF BAMBOO. HOLLOW AND LIGHT.

## 手に入れ方

- 西の浜の奥の竹林に立つ竹を、[石斧](stone-axe.md)で根元から切り倒す（2回叩く。1本で1つ）。足元に斜めに切れた短い切り株が残る

## 使い道

- まだない。竹の水筒、松脂を集める入れ物、竹筏の骨組み、よりよい釣り竿などに使う予定（メインドキュメントの「まだコードにないコンセプト」を参照）

## メモ

- 竹林は川の西側にあり、川を渡れるようになるまで行けない
- 中が空洞で細いので、叩く回数はヤシ（3回）より少ない。石器ナイフや素手では切れず、A を押すと考える仕草をする
- 竹は木ではない（草の仲間）ので、木材の「2×2 で重ねられない」には入れない。長い棒の形（木の槍と同じ 1×3）で、軽いので5本まで重ねられる
- 1本ずつ立つ竹林（株立ちの束ではない）。1本切ると1本取れる
