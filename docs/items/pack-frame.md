# 背負子（PACK FRAME）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（背中） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::PackFrame` |

ゲーム内の説明文:

> WORN ON THE BACK, IT GIVES THE BAG 12 MORE ROOM.

## 手に入れ方

- レシピ: [背負子](../recipes/pack-frame.md)

## 使い道

- GEAR で背中（BACK）に背負う（ITEMS の EQUIP でもその場で背負える）と、バッグが2行（12マス）増えて 6×6 になる

## メモ

- 背負っている間はバッグの外に出る
- 外すときは、増えた行を空けておく必要がある（EMPTY THE EXTRA SPACE FIRST）
