# ツル（VINE）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Vine` |

ゲーム内の説明文:

> A LENGTH OF VINE FOR LIGHT LASHING.

## 手に入れ方

- ツル植物から A で取る（[石器ナイフ](stone-knife.md)が必要。1本1回）。ツル植物はジャングルの縁、川の西側の木と竹のそば（崖の下に33本）、崖の上の高台の木のそば（49本）に生えている
- ナイフがないと考える仕草をする

## 使い道

- レシピの材料: [樹皮の鍋](../recipes/bark-container.md)、[茅葺き](../recipes/thatch.md)、[火起こし器](../recipes/fire-drill.md)
- 水車小屋の壁の材料（×4。竹小舞を縛る）: メインドキュメントの「[水車小屋](../README.md#水車小屋)」

## メモ

- 軽く縛る用途向け。丈夫さが要るもの（石斧、背負子、シェルター）にはロープを使う
