# 掘り棒（DIGGING STICK）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::DiggingStick` |

ゲーム内の説明文:

> A BRANCH WHITTLED TO A POINT. IT LOOSENS HARD EARTH.

## 手に入れ方

- レシピ: [掘り棒](../recipes/digging-stick.md)

## 使い道

- 手に持って、草地の土の露出（草がはげて土がむき出しになった所。2×2 マス）の上か、その手前で B を押すと、地面を突いてほぐし、[土](soil.md)を1つ掘り出す（`SOIL_PER_DIG`）。土の露出は何度でも掘れる
- 湖の岸の粘土の露出で B を押しても、粘土は取れず、考える仕草をする（ねばる粘土に棒が刺さるだけで、すくい上げられない。[竹のスコップ](bamboo-spade.md)が要る）
- 土の露出でも粘土の露出でもない所で B を押しても、何も起きない

## メモ

- 枯れ枝を石器ナイフで削って先を尖らせた棒。硬い地面を突いてほぐす道具で、最初のエリアで作れる
- 掘るときは、しゃがんで2回突き立て（そのたびに土ぼこりが立つ）、ほぐした土を取り出してから立ち上がる
- バッグの絵は先の尖った枝（削った先が白く見える）。地面に落ちた絵も、先が白い棒
- [道具帯](tool-belt.md)に提げられる（バッグの場所を取らずに持ち歩ける）
