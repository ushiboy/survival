# ハシゴ（LADDER）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×4 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Ladder` |

ゲーム内の説明文:

> A LADDER OF LAUAN POLES AND BRANCHES, LASHED WITH ROPE.

## 手に入れ方

- レシピ: [ハシゴ](../recipes/ladder.md)

## 使い道

- 手に持って、崖の岩肌に向かって（上を向いて）B を押すと、崖に立てかける。立てかけたハシゴはバッグから消えて、その場に残る
- 低い崖がひと続きになっている所（くぼみ）では、そのどのマスで B を押しても、ハシゴが届く1か所に立てかける。主人公はそこまで横に歩いてから（崖に向き直って）立てかける。途中で何かにぶつかったら立てかけない
- 届くのは岩肌が2マスまでの崖で、足元が平らな所だけ。今の島では、北の崖のくぼみの真ん中（マップの x 63）だけがそう
- 立てかけたハシゴは、上下に登り降りできる。崖の上の高台へ行ける

## メモ

- ラワン材2本を柱に、枯れ枝を横木にして、ロープで縛ったハシゴ。柱は石斧で削りそろえる
- 岩肌が3マスある崖や、崖でない所に向かって B を押しても、何も起きない
- ハシゴを手に持たずに、崖のくぼみ（どのマスでもよい）で岩肌に向かって A を押すと、よじ登ろうとして2回滑り落ち、考える仕草をする（素手では登れない高さだというヒント）。立てかけた後は出ない
- 一度立てかけたら外せない。どの崖に立てかけたかはセーブに入る
- 手に持っているだけでは絵に出ない（ほかの道具と同じ）
- 地面に置くと、横に寝かせた形で置かれる
