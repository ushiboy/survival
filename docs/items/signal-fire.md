# 狼煙台（SIGNAL FIRE）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 2×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::SignalFire` |

ゲーム内の説明文:

> STONES IN EARTH, WOOD STACKED ON. LIGHT A BRANCH AND A PALM FROND ON IT TO SEND UP SMOKE.

## 手に入れ方

- レシピ: [狼煙台](../recipes/signal-fire.md)

## 使い道

- 手に持って B を押すと、目の前のマスに据える。据えた狼煙台はバッグから消えて、その場に残る
  - 据えられるのは、乾いた地面（砂浜・草地・崖の上の高台）で、何も置かれていないマス（`signal_fire_spot`）。浅瀬や水の上、木や岩のあるマス、焚き火のすぐそば（24px 以内）には据えない（B を押しても何も起きない）
  - 主人公が立っているマスには据えない
- 据えた狼煙台に向かって A を押すと、[火起こし器](fire-drill.md)で火を起こし、[枯れ枝](branch.md) 1本と[ヤシの葉](palm-frond.md) 1枚を燃やして、煙を上げる（詳しくはメインドキュメントの「[狼煙](../README.md#狼煙)」）
  - A が届くのは、目の前（手の届く所。`reach_point`）から台の石の輪の真ん中まで 16px 以内（`SIGNAL_REACH`。絵の石の輪の幅に合わせ、台のマスより広い）か、足元が台に重なっているとき（真ん中から 12px 以内。`SIGNAL_UNDERFOOT`）。主人公は台のほうへ向き直ってから火を起こす。届く台が2台あれば、近いほうに付ける
  - 火起こし器はバッグか道具帯にあればよく、減らない
  - どれかが足りないと、主人公が考える仕草をする
- 煙が上がっている間に、通りかかった飛行機か船に見つかると救助される（1日に1回、1/128。メインドキュメントの「[狼煙](../README.md#狼煙)」）

## メモ

- 石を土に据えて炉にし、その上に木材を井桁に積み、ヤシの葉を載せて火を付ける。生の葉は燻って白い煙を多く出す
- 据えた狼煙台は、焚き火と同じく通り抜けられる（どこにでも据えられるので、ハシゴの足元や細い浜に据えても道をふさがないように）。台の奥を歩けば台の後ろに、手前を歩けば前に主人公が描かれる。一度据えたら動かせない。何台でも据えられる（同じマスには1台だけ）
- 煙が多すぎて焼く・沸かすには向かないので、焚き火の代わりにはならない（そばで焚き火が必要なレシピは作れず、夜の明かりにもならない）
- 燃え尽きても台は残り、また火を付けられる。据えたこと（置物の差分）と、燃えているかはセーブに入る
- 説明文に枯れ枝とヤシの葉の名前と数（A ＝1つずつ）を出している。考える仕草だけでは、狼煙に何が要るか思いつきにくいため
- バッグの絵は、灰色の石を並べた土の盛り上がりに、木材を井桁に積み、緑のヤシの葉を載せた形。据えた狼煙台も同じ絵（火が付くとヤシの葉が焦げ、上に小さな火が出る）。地面に落ちた絵は、土の上に木材2本と石を並べた小さな形
