# 貝殻（SEA SHELL）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 5 |
| コード | `ItemKind::SeaShell` |

ゲーム内の説明文:

> A SCALLOP SHELL WASHED UP ON THE BEACH. HARD AND SMOOTH.

## 手に入れ方

- 砂浜に落ちている貝殻を A で拾う（足元か、目の前のマス）
- 毎朝（日付が変わったとき）、水辺に近い砂浜に最大8つ打ち上がる。浜にある数は、始めにあった数（島に20個）までしか増えない

## 使い道

- レシピの材料: [貝の釣り針](../recipes/shell-hook.md)

## メモ

- 拾うと、貝の釣り針のレシピを思いつく
- ほかの用途（水のすくい、ほら貝の笛、焼いて石灰など）を将来足す候補にしている。メインドキュメントの「まだコードにないコンセプト」を参照
