# 道具帯（TOOL BELT）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（腰） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::ToolBelt` |

ゲーム内の説明文:

> WORN AT THE WAIST, IT HOLDS TWO TOOLS OUT OF THE BAG.

## 手に入れ方

- レシピ: [道具帯](../recipes/tool-belt.md)

## 使い道

- GEAR で腰（WAIST）に締める（ITEMS の EQUIP でもその場で締められる）と、バッグの外に出る（バッグの段数は変わらない）
- 締めている間は、ITEMS のバッグの枠の下に帯の枠が出て、手に持つ道具を2本まで（`BELT_HOOKS`）帯に提げられる。提げた道具はバッグの外に出て、場所を取らない
  - 提げられるのは [石斧](stone-axe.md)・[木の槍](wood-spear.md)・[釣り竿](fishing-rod.md)・[掘り棒](digging-stick.md)・[竹のスコップ](bamboo-spade.md)。[ハシゴ](ladder.md)・[丸太橋](log-bridge.md)・[水車](water-wheel.md)は大きすぎて提げられない
  - 提げるときは、ITEMS で道具を MOVE で持ち上げ、帯の枠（鉤1つが横3マス・縦1マス。`HOOK_CELLS`）まで下ろして A で置く。道具は枠に横に倒して描く。鉤にもう道具があれば入れ替わり、前の道具を持ち上げた状態になる
  - 帯の道具を選ぶと、バッグの中の物と同じコマンドが出る（EQUIP で手に持つ、MOVE でバッグや別の鉤へ動かす、PUT DOWN で地面に置く）
- 提げた道具も「持っている」ものとして扱う
  - GEAR の HAND で、バッグの中の道具と同じように選んで手に持てる（一覧では、どの鉤にあるかが HOOK 1 などと出る）。手に持ったまま帯に提げてもよい（帯の枠でも「E」の印が付く）
  - レシピの道具（[石斧](stone-axe.md)など）としても使える

## メモ

- 外すとき（GEAR の WAIST で TAKE OFF）は、帯と、帯に提げた道具がすべてバッグに戻る。入りきらなければ外せない（NO ROOM IN THE BAG FOR IT）。帯がなくなると帯の枠も ITEMS から消える
- 締められる帯は1本だけ。2本目を締めると、1本目は提げた道具と一緒にバッグに戻る（背負子と同じく付け替えになる）。1本目と道具がバッグに入りきらなければ締められない（NO ROOM FOR THE OLD ONE）
- 提げられないもの: 帯の枠に置けるのは提げられる道具だけ。ほかの物を帯の枠の上に持っていくと、枠が点滅して置けない。鉤の枠に収まらない大きい道具（長さ4マス以上や幅2マス以上）は、提げられない物にする決まり
- 樹皮の帯を編んで腰に締め、ロープで道具を通す輪を縫い付けた物。丈夫さが要る輪はツルではなくロープにする
- バッグの絵は、まっすぐ伸ばした帯（編んだ樹皮が山形の模様になる）の上の端に木の留め具、下の端にロープの結び紐、脇に道具を通すロープの輪が2つ。地面に落ちた絵は、ゆるく曲がって横たわる帯
