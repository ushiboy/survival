# 道具帯（TOOL BELT）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（腰） |
| バッグでの大きさ | 1×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::ToolBelt` |

ゲーム内の説明文:

> WORN AT THE WAIST, IT HOLDS TWO TOOLS OUT OF THE BAG.

## 手に入れ方

- レシピ: [道具帯](../recipes/tool-belt.md)

## 使い道

- GEAR で腰（WAIST）に締めると、バッグの外に出る（バッグの段数は変わらない）
- 締めている間は、手に持つ道具を2本まで（`BELT_HOOKS`）帯に提げられる。提げた道具はバッグの外に出て、場所を取らない
  - 提げられるのは [石斧](stone-axe.md)・[木の槍](wood-spear.md)・[釣り竿](fishing-rod.md)・[掘り棒](digging-stick.md)・[竹のスコップ](bamboo-spade.md)。[ハシゴ](ladder.md)・[丸太橋](log-bridge.md)・[水車](water-wheel.md)は大きすぎて提げられない
  - 提げ方は2つ。ITEMS で道具を選んで HANG ON BELT（空いた鉤があるときだけ出る）、または GEAR で腰の下に並ぶ鉤の行を選び、バッグの中の道具から選ぶ。鉤にもう道具があれば、選んだ道具と入れ替わる（前の道具はバッグに戻る）
  - 鉤の行で TAKE OFF を選ぶと、その道具をバッグに戻す
- 提げた道具も「持っている」ものとして扱う
  - GEAR の HAND で、バッグの中の道具と同じように選んで手に持てる。手に持ったまま帯に提げてもよい
  - レシピの道具（[石斧](stone-axe.md)など）としても使える

## メモ

- 外すとき（GEAR の WAIST で TAKE OFF）は、帯と、帯に提げた道具がすべてバッグに戻る。入りきらなければ外せない（NO ROOM IN THE BAG FOR IT）。帯がなくなると鉤の行も GEAR から消える
- 締められる帯は1本だけ。2本目を締めると、1本目は提げた道具と一緒にバッグに戻る（背負子と同じく付け替えになる）。1本目と道具がバッグに入りきらなければ締められない（NO ROOM FOR THE OLD ONE）
- 提げられないもの: ITEMS で大きい道具を選んでも HANG ON BELT は出ない。鉤の行で選べるのは提げられる道具だけ
- 樹皮の帯を編んで腰に締め、ロープで道具を通す輪を縫い付けた物。丈夫さが要る輪はツルではなくロープにする
- バッグの絵は、まっすぐ伸ばした帯（編んだ樹皮が山形の模様になる）の上の端に木の留め具、下の端にロープの結び紐、脇に道具を通すロープの輪が2つ。地面に落ちた絵は、ゆるく曲がって横たわる帯
