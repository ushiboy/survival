# 火起こし器（FIRE DRILL）

| 項目 | 内容 |
|---|---|
| 種類 | 道具 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::FireDrill` |

ゲーム内の説明文:

> A BOW AND SPINDLE. BURNS FUEL TO LIGHT A FIRE.

## 手に入れ方

- レシピ: [火起こし器](../recipes/fire-drill.md)

## 使い道

- バッグで LIGHT FIRE を選ぶと、燃料を1つ燃やして目の前に焚き火を起こす。燃料は[松ぼっくり](pine-cone.md)があればそれを1個、なければ[枯れ枝](branch.md)を1本。火起こし器は減らない
- 据えた[狼煙台](signal-fire.md)に向かって A を押すと、火を起こして狼煙を上げる（枯れ枝1本とヤシの葉1枚を燃やす）。道具帯に提げていてもよい。火起こし器は減らない

## メモ

- 焚き火は24時間燃える。詳しくはメインドキュメントの「焚き火」を参照
