# 木の槍（WOOD SPEAR）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×3 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::WoodSpear` |

ゲーム内の説明文:

> A SHARPENED BRANCH. THRUST IT TO CATCH CRABS.

## 手に入れ方

- レシピ: [木の槍](../recipes/wood-spear.md)

## 使い道

- 手に持って B で突く。突いた線上の最初の[蟹](crab.md)を捕まえる

## メモ

- 蟹は動いている主人公から逃げるので、立ち止まって待ち、近づいたところを突く
