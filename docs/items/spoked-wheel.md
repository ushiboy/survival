# スポーク車輪（SPOKED WHEEL）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 2×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::SpokedWheel` |

ゲーム内の説明文:

> A HUB, SPOKES AND RIM, ALL TURNED ROUND. IT ROLLS UNDER A LOAD.

## 手に入れ方

- レシピ: [スポーク車輪](../recipes/spoked-wheel.md)（[木工旋盤](wood-lathe.md)のそばで作る）

## 使い道

- レシピの材料: [リアカー](../recipes/handcart.md)（2つ）

## メモ

- ラワン材で、中心のこしきと輪を作る。スポークは、枯れ枝を旋盤で丸く削りそろえたもの
- バッグの絵は、ラワン材の輪（左上が明るい）と8本の白っぽいスポークとこしき。地面に落ちた絵は、寝かせた車輪
