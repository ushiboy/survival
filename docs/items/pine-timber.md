# パイン材（PINE TIMBER）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 2×2 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::PineTimber` |

ゲーム内の説明文:

> A LONG, STRAIGHT LENGTH OF PINE. LIGHT FOR ITS SIZE.

## 手に入れ方

- 崖の上の高台の松を[石斧](stone-axe.md)で切り倒す（4回叩く。1本で2つ）。木にまだ残っている[松ぼっくり](pine-cone.md)も一緒に落ちる

## 使い道

- レシピの材料: [丸太橋](../recipes/log-bridge.md)（川の狭い所にかけて、川を渡る）
- 水車小屋の骨組みの材料（×3。北と南の桁をつなぐ長い梁）: メインドキュメントの「[水車小屋](../README.md#水車小屋)」

## メモ

- 松は軟らかい木なので、叩く回数はヤシ（3回）より多く、広葉樹（5回）より少ない
- 長い材なので、1本から取れる数はラワン材（3つ）より少ない
- 木材（木材・ラワン材・パイン材）は、どれもバッグで 2×2 マスを取り、重ねられない
- 絵はヤシの木材と同じ形を、明るい黄みの色にしている（ラワン材は赤み）
