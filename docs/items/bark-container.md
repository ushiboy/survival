# 樹皮の鍋（BARK POT）

| 項目 | 内容 |
|---|---|
| 種類 | 道具 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::BarkContainer` |

ゲーム内の説明文:

> A POT OF BARK. WATER CAN BE BOILED IN IT.

## 手に入れ方

- レシピ: [樹皮の鍋](../recipes/bark-container.md)

## 使い道

- 焚き火で[生水](raw-water.md)を沸かす（レシピ: [沸かした水](../recipes/boiled-water.md)）
- 魚を煮て油を取る（レシピの道具: [魚油](../recipes/fish-oil.md)。鍋は減らない）
- 生水の水筒を丸ごと沸かす（レシピの道具: [沸かした水の水筒](../recipes/boiled-water-flask.md)。鍋は減らない）

## メモ

- 沸かした水を飲むと、鍋はバッグに戻る。何度でも使える
- 沸かした水が入っている間は、鍋は沸かした水というアイテムになっていて、ほかに使えない。[竹の水筒](bamboo-flask.md)に移せば（FILL FLASK）鍋が空く
