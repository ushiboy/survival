# 樹皮（BARK）

| 項目 | 内容 |
|---|---|
| 種類 | 素材 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::Bark` |

ゲーム内の説明文:

> A STRIP OF BARK FROM A BROADLEAF TREE.

## 手に入れ方

- 広葉樹の幹から A で剥ぐ（[石器ナイフ](stone-knife.md)が必要。1本3回まで。戻らない）
- ナイフがないと考える仕草をする

## 使い道

- レシピの材料: [樹皮の鍋](../recipes/bark-container.md)、[背負子](../recipes/pack-frame.md)

## メモ

- 剥ぎ尽くすと、幹の見た目が剥がれた状態に変わる
