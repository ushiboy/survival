# 竹のスコップ（BAMBOO SPADE）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×3 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::BambooSpade` |

ゲーム内の説明文:

> SPLIT BAMBOO BOUND WITH ROPE. IT LIFTS SOFT, STICKY GROUND.

## 手に入れ方

- レシピ: [竹のスコップ](../recipes/bamboo-spade.md)

## 使い道

- 手に持って、崖の上の湖の南岸にある粘土の露出（湿った土の中の灰色の粘土。2×2 マス）の上か、その手前で B を押すと、[粘土](clay.md)を2つ掘り出す（`CLAY_PER_DIG`）
- 1つの粘土の露出から掘れるのは1日1回。掘ると濡れた穴になり、翌朝、湖の水がしみて元に戻る。掘った日のうちに B を押しても何も起きない
- 草地の土の露出で B を押しても、土は取れず、考える仕草をする（乾いて締まった土に突き立てると竹が割れてしまう。[掘り棒](digging-stick.md)が要る）

## メモ

- 太い竹を節の所で切りそろえ、縦に半分に割って、節を残した側を刃にする。割れが柄まで進まないよう、境目をロープで縛る
- 竹は西の海岸（丸太橋で川を渡った先）にしかないので、作れるのは丸太橋のあと。粘土のある湖の南岸にはハシゴで崖の上へ上がれば行けるので、「粘土を見つける → 掘れない → 西で竹を取る → 掘れる」の順になる
- バッグの絵は、緑の竹の柄、ロープの巻き、内側の白っぽい割った刃。地面に落ちた絵も同じ並び
- [道具帯](tool-belt.md)に提げられる（バッグの場所を取らずに持ち歩ける）
