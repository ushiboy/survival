# 沸かした水（BOILED WATER）

| 項目 | 内容 |
|---|---|
| 種類 | 飲み物 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::BoiledWater` |

ゲーム内の説明文:

> SAFE TO DRINK. EASES THIRST, AND HEALS.

## 手に入れ方

- 焚き火のそばで、[樹皮の鍋](bark-container.md)と[生水](raw-water.md)から作る（レシピ: [沸かした水](../recipes/boiled-water.md)）

## 使い道

- DRINK で飲む。水分 +24、体力 +13
- 飲むと[樹皮の鍋](bark-container.md)が残る
- FILL FLASK で[竹の水筒](bamboo-flask.md)に移す（1杯分。[沸かした水の水筒](boiled-water-flask.md)になる）。鍋は空いて手元に残り、また沸かすのに使える。移せる水筒（空の水筒か、沸かした水が入っていてまだ入る水筒）があるときだけ出る
