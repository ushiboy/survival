# 割った椰子の実（OPENED COCONUT）

| 項目 | 内容 |
|---|---|
| 種類 | 食べ物 |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::OpenedCoconut` |

ゲーム内の説明文:

> CUT OPEN. FLESH TO EAT AND MILK TO DRINK.

## 手に入れ方

- [椰子の実](coconut.md)を石器ナイフで割る（レシピ: [割った椰子の実](../recipes/opened-coconut.md)）

## 使い道

- EAT で食べる。満腹度 +22、水分 +6
- 食べると[椰子の殻](husk.md)が残る
