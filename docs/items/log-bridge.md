# 丸太橋（LOG BRIDGE）

| 項目 | 内容 |
|---|---|
| 種類 | 道具（手） |
| バッグでの大きさ | 1×4 マス |
| 重ねられる数 | 重ねられない |
| コード | `ItemKind::LogBridge` |

ゲーム内の説明文:

> TWO LONG PINE LOGS, LASHED SIDE BY SIDE WITH ROPE.

## 手に入れ方

- レシピ: [丸太橋](../recipes/log-bridge.md)

## 使い道

- 手に持って、川の狭い所の岸で川のほうを向いて（左か右を向いて）B を押すと、川に橋をかける。かけた橋はバッグから消えて、その場に残る
- かけるのは狭い所の真ん中の行だけだが、B を押す場所はそこから上下3行まで広く受け付ける（狭い所の3行より外の、川がまだ3マスある所も含む）。ピンポイントだと、かけられることに気づきにくいため。主人公は真ん中の行まで岸を縦に歩いてから（川に向き直って）かける。途中で何かにぶつかったらかけない（ハシゴを立てかけるときと同じ）
- かけられるのは川の狭い所（[島の設計](../island.md#特別な場所)の「川の狭い所」）だけ。そこでは川が2マスしかなく、両岸が空き地になっている。ほかの所の川に向かって B を押しても何も起きない
- 橋は川の2マスをまたぎ、両端が両岸のマスに乗る。橋の上は歩いて渡れる。最初のエリアから川の向こう（西の海岸と竹林）へ行ける。西の海岸からは、竹林の北東の草の坂を登って、崖の上の川の西側へも行ける

## メモ

- パイン材2本を並べてロープで縛った橋。1本の丸太より歩きやすい。人が渡る重さに耐えるので、ハシゴと同じくツルではなくロープで縛る
- 橋を持たずに、川の狭い所で川に向かって A を押すと、主人公が考える仕草をする（かければ渡れそうだというヒント）。かけた後は出ない
- 最初のエリアから川の狭い所に初めて近づくと、主人公が「！」を浮かべ、そのまま橋をかける東岸のマスまで歩き、川を見て考える（メインドキュメントの「ヒントの出し方」。橋を手に持っていれば考えない）。かける場所のヒントが少なかったため
- 一度かけたら外せない。かけたことはセーブに入る
- 手に持っているだけでは絵に出ない（ほかの道具と同じ）
- 地面に置くと、横に寝かせた形で置かれる
- かけた橋は、川の水の上に重ねて描く（BG1 に草のパレットの土と砂の色で描き、下の水は BG2 のまま見える）。2本の丸太の端の切り口が両岸に出て、その近くをロープで縛ってある。丸太の下には、水と岸に影が落ちる
