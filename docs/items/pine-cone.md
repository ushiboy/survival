# 松ぼっくり（PINE CONE）

| 項目 | 内容 |
|---|---|
| 種類 | 素材（燃料） |
| バッグでの大きさ | 1×1 マス |
| 重ねられる数 | 5 |
| コード | `ItemKind::PineCone` |

ゲーム内の説明文:

> A RESINOUS PINE CONE. IT BURNS WELL.

## 手に入れ方

- 地面に落ちているものを A で拾う（足元か、目の前のマス）
- 今の島では、北の崖のくぼみの真ん中の足元に1つだけ落ちている（崖の上の松から転がり落ちてきたもの）。崖の上の高台にもいくつか落ちている（ハシゴで上がると拾える）
- 高台の松を A で揺すると、何回か揺するごとに1つ落ちる（1本に3つまで。戻らない）
- 松を石斧で切り倒すと、まだ残っていた分が落ちる

## 使い道

- 焚き火の燃料。火起こし器で火を起こすとき、松ぼっくりを持っていれば[枯れ枝](branch.md)より先に1個使う。燃える時間は枯れ枝と同じ（24時間）
- 水車小屋の[囲炉裏](../README.md#囲炉裏)の燃料。くべるときも枯れ枝より先に使う

## メモ

- 枯れ枝（1×2、重ねられない）より小さく、重ねて持てるので、燃料として持ち歩きやすい。枯れ枝は多くのレシピで取り合いになるので、松ぼっくりを燃やせば枯れ枝をレシピに回せる
- 使い道は燃料だけなので、自動で先に燃やす（どちらを燃やすか選ばせない）
- くぼみの足元の1つを拾うと、主人公が「！」を浮かべて崖を見上げ、辺りを見渡し、よじ登ろうとして考える（メインドキュメントの「ヒントの出し方」を参照）
- 種を植えて松を育てるなどは、まだない（「まだコードにないコンセプト」を参照）
