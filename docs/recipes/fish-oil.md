# 魚油

作るもの: [魚油](../items/fish-oil.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [魚](../items/fish.md) ×2、[葉っぱ](../items/leaf.md) ×1 |
| 道具（減らない） | [石器ナイフ](../items/stone-knife.md)、[樹皮の鍋](../items/bark-container.md) |
| 作る場所 | 焚き火のそば（火の付いた囲炉裏のそばでもよい） |
| 一覧での順番 | 29 |

## メモ

- 魚をナイフで切って樹皮の鍋で煮て、浮いた油をすくって葉っぱに包む。鍋は減らない
