# 狼煙台

作るもの: [狼煙台](../items/signal-fire.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [石](../items/stone.md) ×4、[木材](../items/timber.md) ×2、[土](../items/soil.md) ×2 |
| 道具（減らない） | なし |
| 作る場所 | どこでも |
| 一覧での順番 | 27 |

## メモ

- 石を土に据えて炉にし、ヤシの木材を井桁に積む
- 材料はすべて最初のエリアでそろう（石は浜と川辺、木材はヤシの木を石斧で切り倒す、土は最初のエリアの土の露出を掘り棒で掘る）。救助の確率は日ごとなので、早く据えるほど引ける回数が増える
- 火を付けるには、ほかに[火起こし器](../items/fire-drill.md)・[枯れ枝](../items/branch.md)・[ヤシの葉](../items/palm-frond.md)が要る（[狼煙台](../items/signal-fire.md)）
- 石は石器ナイフ・石斧・木の槍・水車・木工旋盤と、土はまだほかに使い道がない
