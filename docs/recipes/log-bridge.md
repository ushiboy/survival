# 丸太橋

作るもの: [丸太橋](../items/log-bridge.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [パイン材](../items/pine-timber.md) ×2、[ロープ](../items/rope.md) ×2 |
| 道具（減らない） | [石斧](../items/stone-axe.md) |
| 作る場所 | どこでも |
| 作れる数 | 1個まで（2個目からは NOT NEEDED NOW。[作れる数](../README.md#作れる数)） |
| 一覧での順番 | 19 |

## メモ

- 長くまっすぐなパイン材2本を並べて、ロープで縛る。人が渡る重さに耐えるので、ツルではなくロープで縛る
- 丸太の両端を削りそろえるのに石斧を使う
- 松を1本切り倒すとパイン材が2つ取れるので、松1本で足りる。パイン材は崖の上でしか取れないので、ハシゴで崖の上へ登ってから作れる
- ラワン材は切ると短い角材になるので、橋には長さが足りない（パイン材でしか作れない）
- ロープは石斧・シェルター・背負子・釣り竿・ハシゴとも取り合いになる
