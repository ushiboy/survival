# 水車

作るもの: [水車](../items/water-wheel.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [ラワン材](../items/lauan-timber.md) ×4、[竹](../items/bamboo.md) ×4、[石](../items/stone.md) ×2、[ロープ](../items/rope.md) ×2 |
| 道具（減らない） | [石斧](../items/stone-axe.md)、[石器ナイフ](../items/stone-knife.md) |
| 作る場所 | どこでも |
| 一覧での順番 | 20 |

## メモ

- ラワン材を石斧で削って軸・腕・輪にし（回す力を支える所なので、硬くて丈夫なラワン材）、竹を石器ナイフで割って羽根にして（水を受けるだけなので、軽い竹）、ロープで縛る
- 軸の両端を受ける支えも作る: ラワン材1本を割って柱2本にし、その上に石を据えて軸受けにする（回し続けても擦り減りにくいように、硬い石で受ける）
- 竹は西の海岸（丸太橋で川を渡った先）にしかないので、作れるのは丸太橋のあと。据える予定地も川の向こうにある
- ラワン材（4本）はハシゴと、石は石器ナイフ・石斧・木の槍と、竹は竹筏（竹 ×10）と、ロープは石斧・シェルター・背負子・釣り竿・ハシゴ・丸太橋とも取り合いになる
