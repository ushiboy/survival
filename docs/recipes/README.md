# レシピ

クラフトで作れるものの一覧です。1つずつ別ファイルにまとめています。

- 材料は作ると使い切ります。
- 道具はバッグに入っていればよく、減りません。
- 焚き火が必要なものは、焚き火から 40px 以内でだけ作れます。
- レシピは最初は見えず、材料を1種類ずつ持つと思いついて CRAFT の一覧に加わります（詳しくは [docs/README.md](../README.md) の「クラフト」）。
- 一覧の順番は、思いついたレシピが CRAFT 画面に並ぶ順番と同じです（`wasm/src/crafting.rs` の `RECIPES`）。
- 同じ物を作るレシピが2つ以上ある物（ロープ）は、CRAFT の一覧では1行にまとまり、その物の最初のレシピの位置に並びます。詳細画面で左右キーで作り方を選びます（詳しくは [docs/README.md](../README.md) の「クラフト」）。
- セーブでは、レシピをそれぞれの名前で保存します。物を作る最初のレシピは、作る物と同じ名前です（`Rope`）。2つ目からは別の名前を付けます（`RopeFromBark`）。

新しいレシピを足すときは、このディレクトリにファイルを追加し、この一覧にも行を足してください。
