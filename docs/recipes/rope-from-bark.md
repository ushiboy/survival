# ロープ（樹皮から）

作るもの: [ロープ](../items/rope.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [樹皮](../items/bark.md) ×3 |
| 道具（減らない） | [石器ナイフ](../items/stone-knife.md) |
| 作る場所 | どこでも |
| 一覧での順番 | 13（CRAFT の一覧では [ロープ](rope.md) と同じ行。詳細画面で左右に切り替える） |
| セーブでの名前 | `RopeFromBark` |

## メモ

- 樹皮の内側の繊維（靭皮）をナイフで細く裂き、撚ってロープにする
- 椰子の殻から作るより材料が多い（1本の広葉樹から取れる樹皮3枚で1本）。椰子の木のない内陸でもロープを作れる
- 樹皮を1つ持つと思いつく。ナイフは思いつく条件に含まない
