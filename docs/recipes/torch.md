# 松明

作るもの: [松明](../items/torch.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [枯れ枝](../items/branch.md) ×1、[椰子の殻](../items/husk.md) ×1 |
| 道具（減らない） | なし |
| 作る場所 | 焚き火のそば |
| 一覧での順番 | 8 |

## メモ

- 枝の先に椰子の殻の繊維を巻き、焚き火で火をつける
- 作ると、バッグには入らず、そのまま持ち歩く状態になる。斧などに持ち替えても照らし続ける
- 作ってから12時間で燃え尽きる。夜の暗闇（約11時間20分）を1本でほぼ越せる長さにしている
- 持っている間にもう1本作ると、残り時間が12時間に戻る
- 椰子の殻はロープにも使うので、取り合いになる
- 作るときは、しゃがんで松明の先を焚き火の炎に差し込む
