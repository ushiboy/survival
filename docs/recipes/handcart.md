## メモ

- ラワン材を石斧で削って荷台と車軸にし、スポーク車輪を両側に付ける。竹2本を持ち手の棒にして、ロープで縛る
- 作るとバッグには入らず、主人公の後ろについてくる（[リアカー](../items/handcart.md)）。1台作ると、2台目は作れない
- スポーク車輪は[木工旋盤](../items/wood-lathe.md)のそばでしか作れないので、「水車 → 旋盤 → 車輪 → リアカー」の順になる
- 材料がバッグの多くを占める（スポーク車輪とラワン材だけで 2×2 が4つ）ので、背負子を背負ったバッグで運ぶ
- ラワン材はハシゴ・水車・木工旋盤・スポーク車輪と、竹は水車・竹のスコップ・竹筏（まだない）と、ロープは石斧・シェルター・背負子・釣り竿・ハシゴ・丸太橋・水車・竹のスコップ・道具帯・木工旋盤とも取り合いになる
