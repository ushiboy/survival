# 竹の水筒

作るもの: [竹の水筒](../items/bamboo-flask.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [竹](../items/bamboo.md) ×1、[枯れ枝](../items/branch.md) ×1 |
| 道具（減らない） | [石斧](../items/stone-axe.md)、[石器ナイフ](../items/stone-knife.md) |
| 作る場所 | どこでも |
| 一覧での順番 | 30 |

## メモ

- 竹を節と節の間で石斧で切り、片方の節に石器ナイフで穴を開け、枯れ枝を石器ナイフで削った木の栓をする
- 竹と枯れ枝をどちらも一度手に入れたことがあると思いつく
- 枯れ枝は多くのレシピや燃料と取り合いになる
