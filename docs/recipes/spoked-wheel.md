# スポーク車輪

作るもの: [スポーク車輪](../items/spoked-wheel.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [ラワン材](../items/lauan-timber.md) ×1、[枯れ枝](../items/branch.md) ×4 |
| 道具（減らない） | [石器ナイフ](../items/stone-knife.md) |
| 作る場所 | [木工旋盤](../items/wood-lathe.md)のそば（40px 以内） |
| 一覧での順番 | 25 |

## メモ

- ラワン材を旋盤で回して、こしきと輪を丸く削る。枯れ枝を同じく旋盤で丸く削りそろえてスポークにし、ナイフで差し込む穴を刻む
- 旋盤のそばでないと作れない（NEEDS A LATHE）。思いつくのは、焚き火のレシピと同じく、材料を1種類ずつ持ったとき（旋盤のそばにいなくても思いつく）
- 一覧では、名前の後ろに旋盤の印（歯車 `*`）が付く。旋盤のそばにいると黄色、離れていると暗くなる
- ラワン材はハシゴ・水車・木工旋盤と、枯れ枝は多くのレシピや焚き火の燃料と取り合いになる
