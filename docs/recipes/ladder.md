# ハシゴ

作るもの: [ハシゴ](../items/ladder.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [ラワン材](../items/lauan-timber.md) ×2、[枯れ枝](../items/branch.md) ×3、[ロープ](../items/rope.md) ×2 |
| 道具（減らない） | [石斧](../items/stone-axe.md) |
| 作る場所 | どこでも |
| 作れる数 | 1回だけ（2回目からは NOT NEEDED NOW。[作れる数](../README.md#作れる数)） |
| 一覧での順番 | 18 |

## メモ

- 長い材2本を柱に、枯れ枝を横木にしてロープで縛る、石器で作れる形のハシゴ。人が登る重さに耐えるので、ツルではなくロープで縛る
- 柱の材を削りそろえるのに石斧を使う
- 崖の上でしか取れない素材は使わない（崖の上へ行くためのハシゴなので）。最初のエリアの素材だけで作れる
- ラワン材はこれが初めての使い道。ロープは石斧・シェルター・背負子・釣り竿とも取り合いになる
