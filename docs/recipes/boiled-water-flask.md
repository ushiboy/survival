# 沸かした水の水筒

作るもの: [沸かした水の水筒](../items/boiled-water-flask.md)

| 項目 | 内容 |
|---|---|
| 材料（使い切る） | [生水の水筒](../items/raw-water-flask.md) ×1（何杯入っていてもよい） |
| 道具（減らない） | [樹皮の鍋](../items/bark-container.md) |
| 作る場所 | 焚き火のそば（火の付いた囲炉裏のそばでもよい） |
| 一覧での順番 | 31 |

## メモ

- 水筒の生水を樹皮の鍋で少しずつ沸かしては水筒に戻す。出来上がるのは、元と同じ杯数の沸かした水の水筒で、鍋は手元に残る
- 生水の水筒が2本以上あるときは、いちばん多く入っている1本を沸かす
- 生水の水筒を一度手に入れたことがあると思いつく（道具の鍋と焚き火は、思いつくのに要らない）
- かかる時間は、ほかの焚き火のレシピと同じ（杯数によらない）
