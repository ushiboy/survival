# Castaway Island 仕様

ゲームの考え方と、いま実装されている仕様をまとめたドキュメントです。素材・道具・食べ物は [items/](items/README.md)、レシピは [recipes/](recipes/README.md) で、1つずつファイルに分けて管理します。

仕様を変えたときは、コードと一緒にここも更新してください。数値はコードの定数から書き写しているので、ずれたらコードの方が正しい値です。

## コンセプト

無人島に漂着したプレイヤーが島内を冒険し、狩りや採取で素材を集めて道具や食料を作り、生き延びるゲームです。

作った道具によっては島から脱出してゲームクリアすることもできます。ただし、何を目指すかはプレイヤーの楽しみ方次第です。

- 最短日数での脱出を目指す
- 最長の生存日数を目指す
- 文化レベルをあげて、快適な生活を楽しむ

### 発見

コンセプトの柱の一つが「発見」です。

- プレイヤーは、島内で条件を満たすことでできることが増えていきます。
- ゲームは親切に案内はしません。与えるのは「なにかできそう」というヒントだけです。
- 集めたアイテムで何ができるのかを見つけること自体が、楽しみの一つです。

## 設計の方針

### ヒントの出し方

- やり方を直接教えるメッセージは出しません。
  - 「ナイフが必要です」「葉っぱで水を汲めます」のような案内はしません。
  - 操作説明（ページ下の操作パネル）にも、条件付きで解放される行動のやり方は書きません。
- 代わりに、プレイヤーが条件を満たさずに行動しようとしたとき、主人公が **考える仕草** をします。
  - 1秒ほど立ち止まり、あごに手を当てて、頭上の吹き出しに「…」の点を1つずつ増やします。
  - 「ここで何かできそうだ」とだけ伝わり、何が足りないかは伝えません。
  - いま考える仕草が出る場所は次のとおりです。

    | 場所 | 足りないもの |
    |---|---|
    | 水汲み場 | 葉っぱ |
    | ツル植物 | 石器ナイフ |
    | 樹皮が残っている広葉樹 | 石器ナイフ |
    | 魚の影が泳いでいる水辺（目の前の水） | 釣り竿 |

  - 取り尽くした木や、実のないヤシのように「もう何もない」ものには出しません。
- レシピは最初から見えません。材料を1種類ずつ持った時点で思いつき、クラフト画面の一覧に加わります（「クラフト」の節を参照）。
  - 思いついた瞬間、主人公の頭上に「！」の吹き出しが一瞬出ます。考える仕草の「…」と対になる「ひらめいた」の合図で、何を思いついたかはその場では言いません。
  - 道具と焚き火は思いつく条件に含めません。詳細画面で「ナイフがない」「火が要る」とわかること自体が、「なにかできそう」のヒントになります。
- 思いついたレシピの説明文に書くのは「何に使えるか」までで、手に入れ方は書きません。
- 道具は「バッグに入れて持っているだけで使える」ものが基本です。ナイフのように、持っていれば採取や調理の条件を満たすものがあります。

### 現実らしさ

- 材料や道具の必要条件は、現実に照らして違和感がないように決めます。
  - 例: 樹皮やツルは素手では取れず、刃物で切る。
  - 例: 椰子の実は素手では割れず、ナイフで開ける。
  - 例: 丈夫さが要る石斧や背負子は、ツルではなくロープで縛る。
- 焚き火が必要なもの（焼く・沸かす・火をつける）は、焚き火のそばでだけ作れます。

### 資源の取り合い

- 一つの素材を複数の用途で取り合うようにして、何に使うかを選ばせます。
  - 例: 椰子の殻（HUSK）は、ロープにも松明にも使う。
- 一度きりの資源と、毎日回復する資源を分けています。詳しくは「採取」を参照してください。

### SFC らしさ

- 見た目と描画は、スーパーファミコン（Mode 1）の制約に合わせています。
  - 色数、スプライト枚数、VRAM 容量、HDMA、カラー演算などです。
- 技術的な詳細はリポジトリ直下の [README](../README.md) にあります。

## まだコードにないコンセプト

方針としては決まっているものの、まだ実装していないものです。

- **島からの脱出（ゲームクリア）**: 作った道具（筏など）で島を出られるようにする。
- **文化レベル**: 生活を快適にしていく度合い。作った物や暮らしぶりで上がっていく。
- **遊び方の記録**: 脱出までの日数、生存日数など、プレイヤーが目指す指標。
- **体力の最大量の成長**: 体力ゲージの最大量を増やせるようにする。飢え・渇き・疲れ・睡眠の回復は最大量に対する割合で決めてあるので、倒れるまでの日数は変わらない。成長が効くのはケガなど一度に受けるダメージに対して（ダメージは絶対量で決める予定）。食べ物の回復量を割合にするかは、そのときに決める。
- **マップの拡張**: 今のマップは島全体の一部のエリアで、さらに広げる予定（島全体で今の50倍以上の広さ）。島の端から端まで、つなぎ目なく歩けるようにする。
  - 島の作り方（設計図・特別な場所・細部）は [島の設計](island.md) にある。設計図を描き足して広げていく。
  - 「橋をかけられる場所」「小屋を建てられる広場」のような特別な場所を足す。島を作るときにその条件（川幅、平らな土地など）を満たすように地形を整え、表示で教えず、地形でさりげなく伝える。
- **離れた場所の時間の追いつき**: 島は区画ごとに、最後に動いていた時刻を覚えている（「島」を参照）。区画が動き出すときに、離れていた時間の分だけ蟹が増える・減るなどをまとめて計算する仕組みを入れる。今は何も変わらず、離れたときの状態から続く。
- **資源の再生**: 椰子の実や樹皮は、今は一度取ったら戻らない。
- **貝殻のほかの用途**: 今は釣り針にだけ使う。水のすくい（葉っぱの代わりに何度でも水を汲める）、ほら貝の笛（船に合図して救助を呼ぶ、脱出ルートの一つ）、焼いて石灰、塩づくりの器、飾りなどが候補。
- **釣りのエサ**: エサ（蟹の身など）を付けると掛かりやすくなる。
- **松明の持ち歩き中の見た目**: 斧を振る・収穫・食事などの動作中は、松明の絵が消える（光は消えない）。

## ゲームの流れ

1. 砂浜に倒れた状態から目を覚まして始まります（A・B ボタンで飛ばせます）。
2. 島を歩いて素材を集め、バッグの CRAFT で道具や食べ物を作ります。
3. 食べる・飲む・眠ることで生き延びながら、できることを増やしていきます。
4. 体力が0になると倒れて、ゲームオーバー（バッドエンド）です。画面が暗くなり、倒れた日時と生き延びた時間が出ます。START で最初からやり直します。

## 島

今のマップは、島全体のうちの一部のエリア（南の浜辺）です。今後さらにマップを広げる予定です。以下の広さや配置の数は、今のエリアについての値です。

- 今のエリアの広さは 96×48 マス（1マス 16px）です。最初のエリア（西の64×48マス）と、その東の海岸からなります。
- 島は毎回同じ形です。手で描いた設計図から作ります。設計図・特別な場所・細部の置き方は [島の設計](island.md) を参照してください。
- 地形は、深い海・浅瀬・砂浜・草地・ジャングルです。
  - 浅瀬は歩けますが、遅くなり、走れません。脚が水に隠れます。
  - 深い海と川は通れません。
- 川が1本流れていて、上流に **水汲み場** が1か所あります。

### 区画（チャンク）

島は 32×32 マスの区画に分けて扱います。島の地形・置物・採取の状態は全体を常に覚えていますが、画面に出す準備と生き物の動きは、プレイヤーの近くの区画だけで行います。

- **地面のタイル**: 画面とその周り（16px）の区画はすぐに作り、その先（区画の半分＝256px）の区画は1フレームに4行ずつ前もって作ります。画面から1区画分（512px）より離れた区画のタイルは捨てて、VRAM を空けます。
- **生き物の動き**: 蟹・魚・落ちて転がっているアイテムは、画面から256px以内の区画にいるものだけが動きます。画面から320px以上離れた区画は眠り、そこにいるものは止まります。カモメは空を飛んでいるので、いつも動きます。
- **時間の追いつき**: 眠っていた区画が動き出すときに、眠っていた時間（ゲーム内の分）がわかるようになっています。今はそれを使った変化はなく、止まったときの状態から続きます（「まだコードにないコンセプト」を参照）。
- 焚き火・松明・貝殻の打ち上げ・魚の補充は、時刻で決まるので、区画が眠っていても遅れずに進みます。

## 時間

- ゲーム内の1分は 20 フレーム（1/3 秒）です。1時間は約20秒、1日は約8分かかります。
- 1日目の朝7時から始まります。
- 夜の暗闇は 18:17 頃から翌 5:38 頃まで、約11時間20分続きます。
  - 暗闇の外は真っ暗で、見えるのは光の届く範囲だけです。
  - 光源は、持ち歩いている松明とすべての焚き火で、同時にいくつでも照らせます。
  - 夕方と明け方は、暗くなる前・明るくなった後に空の色が変わります。

## 主人公の状態

### 体力

- 満腹度・水分と同じゲージで、最大は64です（画面左上の一番上、赤いゲージ）。
- **0になると倒れて、ゲームオーバーです。**
- 減り方・戻り方は、すべて「最大量の64分の1が何分で減る（戻る）か」で決めています。最大量が変わっても、倒れるまでの日数は変わりません。

| 状況 | 体力の増減（64分の1あたり） |
|---|---|
| 起きている（疲れ） | 75分で1減る（16時間で約13、ゲージの約5分の1） |
| 水分が0 | 68分で1減る（起きていても眠っていても） |
| 満腹度が0 | 10時間で1減る（起きていても眠っていても） |
| 眠っている | 15分で1戻る（シェルターの中では10分で1） |
| 眠っている（満腹度か水分が0） | 疲れの分しか戻らない（下を参照） |

- **疲れ**: 画面には出ない値です。起きている1分ごとに1たまり、眠っている1分ごとに2減ります（8時間眠ると16時間分の疲れが取れる）。
  - 満腹度か水分が0のときは、眠っても疲れが取れた分（起きていて減った分）しか体力は戻りません。それ以上は回復しません。
  - 疲れが取れたあとも眠り続けられますが、何も回復せず、飢えと渇きだけが進みます。
- 焼き蟹・焼き魚を食べる、沸かした水を飲むと、13回復します。満腹度か水分が0のままなら回復しません（沸かした水は飲めば水分が戻るので回復します）。
- 目安（朝7時に満タンから始めた場合）:

| 過ごし方 | 倒れるまで |
|---|---|
| 水も食べ物もあり・普通に眠る | 倒れない（夜に約5分の1減り、一晩眠ると戻る） |
| 水も食べ物もあり・眠らない | 約3.3日 |
| 水がない | 約3〜4日（普通に眠って約3.2日。眠らないと約1.8日） |
| 食べ物がない（水はある） | 約3〜4週間（普通に眠って約23日。眠らないと約3日） |

### 満腹度と水分

- どちらもゲージで、最大は64です。
- 起きているとき、満腹度は15分ごと、水分は10分ごとに1ずつ減ります。
  - 満タンから空になるまで、満腹度は約16時間、水分は約10時間40分です。
- 眠っているとき、満腹度の減り方は起きているときの6分の1（シェルターの中では12分の1）、水分は2分の1（シェルターの中では3分の1）です。眠っていても息で水分は抜けていくためです。
- 回復量は食べ物・飲み物ごとに決まっています。各アイテムのページを参照してください。
- **満腹度が0のあいだは、弱って走れず、歩く速さも4分の3になります**（歩く足取りもゆっくりになる）。満腹度が1以上に戻ると元に戻ります。

### 移動

- 歩く（約1.3px/フレーム）、走る（R を押しながら。約2.2px/フレーム）、浅瀬を歩く（約0.7px/フレーム）の3つです。
- 満腹度が0のあいだは走れず、歩く・浅瀬を歩く速さが4分の3になります。
- 障害物の角に少し引っかかったときは、自動で横にずらして通り抜けます。

### 眠る

- Y でその場に横になります。浅瀬では眠れません。
- 眠っている間は、ゲーム内の時間が1フレームに2分ずつ進みます。
- 眠ると体力と疲れが戻ります（「体力」を参照）。
- いつでも好きなだけ眠れますが、満タンでそれ以上は回復しません。そのあいだも飢えと渇きは進みます。
- バッグにシェルターがあると、シェルターを張って中で眠ります。主人公は見えなくなり、シェルターから Zzz が出ます。
  - 体力の戻りが速くなり、空腹と渇きの減りがさらに遅くなります。
- A・B・Y のどれかを押すと起きます。

## 行動

| ボタン | 行動 |
|---|---|
| A | 足元の物（貝殻も）を拾う／ヤシを揺する（長押しで揺すり続ける）／ツル・樹皮・葉っぱを取る／水を汲む |
| B | 手に持った道具を使う（石斧を振る、木の槍で突く、釣り竿で糸を投げる・合わせる） |
| X | バッグを開く・閉じる |
| Y | 眠る |
| R | 走る |
| START | ポーズ（倒れたあとは最初からやり直す） |

- 必要な道具や素材がないまま A を押すと、考える仕草をします（「ヒントの出し方」を参照）。

## 釣り

- 浅瀬、川、岸に近い海には、魚が18匹泳いでいます。昼は水の中に黒い影として見えます。夜は見えませんが、魚はいて、釣ることもできます。
- 釣り方:
  1. 釣り竿を手に持ち、水に向かって B を押すと糸を投げます。目の前の水面（約34〜46px先）にウキが浮きます。投げた先が水でなければ何も起きません。浅瀬に入っている間は投げられません。
  2. ウキから 56px 以内に魚がいると、寄ってきます。ウキに着くと何度か（1〜3回）つついてウキが揺れ、そのあとウキが沈みます。
  3. ウキが沈むと同時に水しぶきが上がります。沈んでいる間（45フレーム、0.75秒）に B を押すと釣れます。魚は水から跳ね上がり、主人公の横の砂に落ちるので A で拾います。
- 失敗するとき:
  - 沈む前に B を押すと、糸を引き上げてしまい、寄ってきた魚は逃げます。
  - 沈んでいる間に押せないと、魚は逃げます。糸はそのまま残り、別の魚を待てます。
  - 移動するか A を押すと、糸を引き上げます。
- 逃げた魚は、しばらく（300フレーム）ウキに寄ってきません。
- 釣った魚の代わりは、3時間後（ゲーム内）に画面の外のどこかに現れます。
- 釣り針は使っても減りません。

## バッグ

- 6×4 マスの枠に、アイテムをそれぞれの大きさで詰めます。
  - 向きを90度回して入れられます。重ねることはできません。
- 同じ種類の一部は重ねて1マスに入ります（葉っぱ20枚、椰子の殻・ロープ・ヤシの葉は5つまで）。
- 背負子を背負うと、2行増えて 6×6 マスになります。
- 入りきらないときはバッグが開き、あふれた物を手に持った状態になります。場所を空けて入れるか、地面に置きます。
- 画面は ITEMS・CRAFT・GEAR の3つのタブに分かれています。
  - **ITEMS**: アイテムを選んで使う・持ち替える・動かす・置くことができます。
    - 置く操作は、生水だけは POUR OUT（流す）です。生水は地面に置けません。
  - **CRAFT**: レシピ一覧（1ページ8件、左右でページ送り）から選び、材料と説明を見て作ります。
  - **GEAR**: 手（HAND）と背中（BACK）の装備を付け替え・外しできます。
- バッグを開いている間は、ゲーム内の時間が止まります。

### 装備

- **手（HAND）**: 石斧、木の槍、釣り竿。
- 松明は装備ではなく、作ると持ち歩く状態になります。手の装備枠は使わず、道具と同時に持てます（[松明](items/torch.md)を参照）。
  - 手に持つ道具もバッグの中に入ったまま場所を取ります。
  - 手が空いているときに道具を手に入れると、自動で手に持ちます。
- **背中（BACK）**: 背負子。背負っている間はバッグの外に出て、バッグが広がります。

## クラフト

- レシピは材料（使い切る）、道具（持っていればよく、減らない）、焚き火のそばかどうか、の3つで決まります。

### レシピを思いつく

- 始めは、どのレシピも知りません。CRAFT の一覧は空です。
- レシピの材料を **1種類につき1つずつ** 同時にバッグに持つと、そのレシピを思いつきます。
  - 必要な数が揃っていなくても思いつきます。例: シェルターは枯れ枝・ロープ・茅葺きを1つずつ持てば一覧に出て、詳細画面で必要な数（4・2・2）がわかります。
  - 道具と焚き火は条件に含めません。
- 思いついたとき:
  - 主人公の頭上に「！」の吹き出しが約1秒出ます。動作は止まりません。
  - バッグの中でクラフトして思いついたときは、吹き出しは出ず、一覧にすぐ加わります。
- 一覧では、まだ開いていないレシピの名前の後ろに「!」が付きます。一度詳細を開くと消えます。
- 一度思いついたレシピは、材料を手放しても一覧から消えません。
- まだ思いついていないレシピは、行も総数も表示しません。
- 思いついたレシピは、ゲームの状態として持っています。セーブ機能はまだないので、ページを開き直すとリセットされます。

### 作る
- 焚き火が必要なレシピでは、主人公がしゃがんで材料を火にかざす動きのあと、出来上がった物がバッグに入ります。
- 足りないときは次のように表示されます。
  - 材料: NOT ENOUGH MATERIALS
  - 道具: MISSING A TOOL
  - 焚き火: NEEDS A FIRE
- 一覧は [recipes/](recipes/README.md) を参照してください。

## 焚き火

- 火起こし器をバッグで使う（LIGHT FIRE）と、枯れ枝1本を燃料にして、目の前の地面に焚き火を起こします。
- 起こせないときは次のように表示されます。
  - 枯れ枝がない: NEEDS A BRANCH TO BURN
  - 地面が乾いていない、通れない場所: NO DRY GROUND HERE
  - すぐそばに焚き火がある: A FIRE IS ALREADY HERE
- 24時間燃え続け、最後の2時間は火が小さくなります。
- 焚き火から 40px 以内が「焚き火のそば」で、焚き火が必要なレシピを作れます。
- 夜は周りを照らします。

## デバッグ機能

- URL に `?debug=true` を付けるとデバッグパネルが出ます。好きなアイテムを個数を指定してバッグに入れられ、全レシピを解放するボタンもあります。体力・満腹度・水分を満タンにする、満腹度や水分を0にする、体力を1にするボタンもあります。
- Shift（SELECT）で時刻を3時間進められます。O で服装を切り替えられます。この2つのキーの説明もデバッグパネルに出ます。
- 開発用のスナップショットツールについては、リポジトリ直下の [README](../README.md) を参照してください。
