# Castaway Island 仕様

ゲームの考え方と、いま実装されている仕様をまとめたドキュメントです。開発の手順やツールはリポジトリ直下の [README](../README.md) にあります。

- 素材・道具・食べ物: [items/](items/README.md)（1つずつファイルに分けています）
- レシピ: [recipes/](recipes/README.md)（同じく1つずつ）
- 島の設計図・特別な場所・細部の置き方: [島の設計](island.md)
- セーブの中身と形式: [セーブと再開](save.md)
- 描画と SFC の制約: [描画](rendering.md)

仕様を変えたときは、コードと一緒にここも更新してください。数値はコードの定数から書き写しているので、ずれたらコードの方が正しい値です。

## コンセプト

無人島に漂着したプレイヤーが島内を冒険し、狩りや採取で素材を集めて道具や食料を作り、生き延びるゲームです。

作った道具によっては島から脱出してゲームクリアすることもできます（今ある脱出の手段は、運次第で救助を待つ[狼煙](#狼煙)）。ただし、何を目指すかはプレイヤーの楽しみ方次第です。

- 最短日数での脱出を目指す
- 最長の生存日数を目指す
- 文化レベルをあげて、快適な生活を楽しむ

### 発見

コンセプトの柱の一つが「発見」です。

- プレイヤーは、島内で条件を満たすことでできることが増えていきます。
- ゲームは親切に案内はしません。与えるのは「なにかできそう」というヒントだけです。
- 集めたアイテムで何ができるのかを見つけること自体が、楽しみの一つです。

## 設計の方針

### ヒントの出し方

- やり方を直接教えるメッセージは出しません。
  - 「ナイフが必要です」「葉っぱで水を汲めます」のような案内はしません。
  - 操作説明のダイアログにも、条件付きで解放される行動のやり方は書きません。
- 代わりに、プレイヤーが条件を満たさずに行動しようとしたとき、主人公が **考える仕草** をします。
  - 1秒ほど立ち止まり、あごに手を当てて、頭上の吹き出しに「…」の点を1つずつ増やします。
  - 「ここで何かできそうだ」とだけ伝わり、何が足りないかは伝えません。
  - いま考える仕草が出る場所は次のとおりです。

    | 場所 | 足りないもの |
    |---|---|
    | 水汲み場（滝壺の東西の岸と、崖の上の川の岸） | 葉っぱ |
    | ツル植物 | 石器ナイフ |
    | 樹皮が残っている広葉樹 | 石器ナイフ |
    | 竹（根元に向かって A） | 石斧（手で折ったりナイフで切ったりはできない） |
    | 魚の影が泳いでいる水辺（目の前の水） | 釣り竿 |
    | 崖のくぼみ（ハシゴが届く所。くぼみのどのマスでもよい）。岩肌に向かって A を押すと、岩に手をかけてよじ登ろうとし、2回滑り落ちてから考える | ハシゴ（手に持っていない） |
    | 川の狭い所の岸（真ん中の行から上下3行のどこでもよい。川のほうを向いて） | 丸太橋（手に持っていない） |
    | 水車小屋の予定地の岸（予定地の行から上下3行のどこでもよい。川のほう（東）を向いて） | 水車（手に持っていない。据えた後は出ない） |
    | 据えた水車の隣の岸の近く（旋盤を据える4マスから縦横4マス以内。向きは問わない） | 木工旋盤（手に持っていない。水車を据える前と、旋盤を据えた後は出ない。リアカーを引いているときや、置いたリアカーに向かっているときは出ない） |
    | 草地の土の露出（上に立つか、手前で A。掘り棒を持っていても A では掘れない） | 掘り棒（B で掘る） |
    | 湖の南岸の粘土の露出（同じく A。掘った日のうちは出ない） | 竹のスコップ（B で掘る） |
    | 土の露出で竹のスコップを手に B／粘土の露出で掘り棒を手に B | 合う道具（硬い土に竹は割れ、ねばる粘土は棒ではすくえない） |
    | 据えた狼煙台（火が付いていないもの。向かって A） | 火起こし器・枯れ枝・ヤシの葉のどれか（狼煙台の説明文に枯れ枝とヤシの葉の名前が出る） |

  - 崖のくぼみの真ん中の足元には、崖の上の松から転がり落ちた [松ぼっくり](items/pine-cone.md) が1つだけあります。拾うと、主人公の頭上に「！」が浮かび（レシピを思いついたときと同じ）、崖を見上げ、ゲーム開始時と同じように左右を見渡して、もう一度見上げます。ハシゴを持っていなければ、そのまま崖に歩み寄って、よじ登ろうとして2回滑り落ち、考える仕草をします（上の表の「崖のくぼみ」と同じ動き）。この出来事は一度だけです（拾った松ぼっくりはなくなり、それがセーブに残る）。
  - 最初のエリアから川の狭い所に初めて近づくと（橋をかける東岸のマスから4マス以内。`BRIDGE_NOTICE_CELLS`）、主人公が立ち止まって頭上に「！」を浮かべ、そのまま橋をかける東岸のマス（狭い所の真ん中の行）まで自分で歩いて川のほう（西）を向き、考える仕草をします（上の表の「川の狭い所の岸」と同じ）。丸太橋を手に持っていれば、岸まで歩くところまでで、考える仕草はしません（あとは B でかけるだけなので）。この出来事は一度だけで、見たことはセーブに入ります。橋をもうかけてあるときは起きません。川の向こう（西の海岸）の側では起きません。
  - 水車小屋の予定地に初めて近づくと（予定地の岸から4マス以内。`MILL_NOTICE_CELLS`。川の西側、西の海岸の広場にいるときだけ。最初のエリアの川岸から川越しに近づいても起きない）、主人公が立ち止まって頭上に「！」を浮かべ、そのまま予定地の岸まで自分で歩いて川のほうを向き、考える仕草をします（上の表の「水車小屋の予定地の岸」と同じ）。水車を手に持っていれば、岸まで歩くところまでで、考える仕草はしません（あとは B で据えるだけなので）。この出来事は一度だけで、見たことはセーブに入ります。水車をもう据えてあるときは起きません。
  - 取り尽くした木や、実のないヤシのように「もう何もない」ものには出しません。何をしても届かない、岩肌が3マスある崖にも出しません（ハシゴを持って B を押しても何も起きない）。
- レシピは最初から見えません。材料を1種類ずつ持った時点で思いつき、クラフト画面の一覧に加わります（「クラフト」の節を参照）。
  - 思いついた瞬間、主人公の頭上に「！」の吹き出しが一瞬出ます。考える仕草の「…」と対になる「ひらめいた」の合図で、何を思いついたかはその場では言いません。
  - 道具と焚き火は思いつく条件に含めません。詳細画面で「ナイフがない」「火が要る」とわかること自体が、「なにかできそう」のヒントになります。
- 体調を崩したことも、文字では伝えません。お腹を壊すと、顔色が青白くなり、お腹を押さえて歩き、体力のゲージが紫になって、その右に前かがみでお腹を押さえる人のピクトグラムが出ます。生の物を口にしたその場で始まるので、プレイヤーは「生で食べたせいだ」「火を通せば大丈夫かもしれない」と自分で気づきます（「主人公の状態」の「体調」）。
- 思いついたレシピの説明文に書くのは「何に使えるか」までで、手に入れ方は書きません。
- 道具は「バッグに入れて持っているだけで使える」ものが基本です。ナイフのように、持っていれば採取や調理の条件を満たすものがあります。

### 現実らしさ

- 材料や道具の必要条件は、現実に照らして違和感がないように決めます。
  - 例: 樹皮やツルは素手では取れず、刃物で切る。
  - 例: 椰子の実は素手では割れず、ナイフで開ける。
  - 例: 丈夫さが要る石斧や背負子は、ツルではなくロープで縛る。
  - 例: 乾いて締まった土は尖った掘り棒でほぐし、ねばる粘土は竹のスコップですくう（棒では粘土をすくえず、竹のスコップは硬い土に突き立てると割れる）。
- 焚き火が必要なもの（焼く・沸かす・火をつける）は、焚き火のそばでだけ作れます。

### 資源の取り合い

- 一つの素材を複数の用途で取り合うようにして、何に使うかを選ばせます。
  - 例: 椰子の殻（HUSK）は、ロープにも松明にも使う。
  - 例: 樹皮（BARK）は、樹皮の鍋・背負子・道具帯にも、ロープにも使う。
  - 例: 竹（BAMBOO）は、水車・竹のスコップ・リアカーに使い、竹筏（まだない）にも使う予定。
  - 例: ヤシの葉（PALM FROND）は、茅葺き（シェルターの屋根）にも、毎日の狼煙にも使う。枯れ枝（BRANCH）は多くのレシピに使い、焚き火の燃料と狼煙の火種にもなる。
- 一度きりの資源と、毎日回復する資源を分けています。詳しくは「採取」を参照してください。

### SFC らしさ

- 見た目と描画は、スーパーファミコン（Mode 1）の制約に合わせています。
  - 色数、スプライト枚数、VRAM 容量、HDMA、カラー演算などです。
- 技術的な詳細は [描画（SFC Mode 1 の制約）](rendering.md) にあります。

## まだコードにないコンセプト

方針としては決まっているものの、まだ実装していないものです。

- **島からの脱出（ゲームクリア）**: 脱出の手段をいくつか用意する。1つ目の[狼煙](#狼煙)（運次第で救助を待つ）はもうある。ほかの手段（筏など）を足していく。
  - 狼煙での救助の場面は、今は仮のもの（画面が暗くなり、RESCUED と記録が出るだけ）。救助の場面を作り込む。
- **文化レベル**: 生活を快適にしていく度合い。作った物や暮らしぶりで上がっていく。
- **遊び方の記録**: 脱出したときの記録（脱出した日、作ったアイテムの種類、見つけたレシピの数）は、脱出の画面に出るようになった（「[狼煙](#狼煙)」）。倒れたときに出す記録（今は倒れた日時と生き延びた時間だけ）や、ゲームをまたいで記録を残すかは、まだ決めていない。
- **体力の最大量の成長**: 体力ゲージの最大量を増やせるようにする。飢え・渇き・疲れ・睡眠の回復は最大量に対する割合で決めてあるので、倒れるまでの日数は変わらない。成長が効くのはケガなど一度に受けるダメージに対して（ダメージは絶対量で決める予定）。食べ物の回復量を割合にするかは、そのときに決める。
- **マップの拡張**: 今のマップは島全体の一部のエリアで、さらに広げる予定（島全体で今の50倍以上の広さ）。島の端から端まで、つなぎ目なく歩けるようにする。
  - 島の作り方（設計図・特別な場所・細部）は [島の設計](island.md) にある。設計図を描き足して広げていく。
  - 「橋をかけられる場所」「小屋を建てられる広場」のような特別な場所を足す。島を作るときにその条件（川幅、平らな土地など）を満たすように地形を整え、表示で教えず、地形でさりげなく伝える。
- **崖の上と西への道**: 崖の上の土地は、これから作る（今の崖の上は、松（少し広葉樹）と茂みの高台と、その北の大きな湖（「島」を参照）。湖の向こう岸はまだ何もない高台）。
  - 崖の上へ行ってからは、パイン材で軽いハシゴを作れるようにしてもよい（今のハシゴは崖の上でしか取れない物を使わない。取りに行けずに詰まるため）。
  - 西へは、崖の上から下りる道も作って橋を近道にするか、橋だけを道にするかを、西のエリアを作るときに決める。
- **針葉樹（松）**: 標高の高い所（崖の上から火山へ向かう山道）に生える。低い所は広葉樹（ラワン）、高い所は針葉樹と、高さで植生が変わる。崖の縁の近くにも生やして、最初のエリアから見えるようにする（登る動機になる）。今は崖の上の高台の木の多くが松で、くぼみのすぐ上の1本が崖の下から見える。揺すると[松ぼっくり](items/pine-cone.md)が落ち、石斧で切り倒すと[パイン材](items/pine-timber.md)が取れる（「採取」を参照）。火山へ向かう山道はまだない。
  - **パイン材**: 軽く、長くまっすぐ。[丸太橋](items/log-bridge.md)、筏など、長さや軽さが要る物に使う（今の使い道は丸太橋だけ）。ラワン材は硬さと丈夫さが要る道具や建物向きで、2つの木材を使い分ける。
  - **松脂**: 幹に傷を付けると、時間をかけてにじみ出る。竹を足すときに、竹で作る入れ物（集めるための容器）を作り、それを使うと集められるようにする。防水（筏の継ぎ目）、接着（道具の刃を柄に固める）、長く燃える松明の燃料などに使い、使い道を取り合いにする。
  - **松ぼっくり**: アイテムと燃料としての使い道、松を揺すって落とすことは、もうある（[松ぼっくり](items/pine-cone.md)）。
    - あとから足す候補: 種を高台に植えると、時間をかけて松が育つ（パイン材を増やせる。燃やすか植えるかの取り合いになる）。湿ると閉じ、乾くと開くので、天気の仕組みを作るときに雨の予兆にする。
  - あとから足す候補: 肥松（切り株を割ると取れる脂の多い芯。火を付けやすい）、松葉（落ちていて毎日回復する。寝床の敷き物や火口）。
- **水車小屋**: 据えた[水車](items/water-wheel.md)の隣（水車小屋の予定地の空き地。「島」を参照）に建てる小屋。水車の力で物を作るだけの小屋ではなく、寝泊まり・資材の保管・道具を作って据える場所にする。水車はもうある（作って予定地の川に据えると回り、隣に据えた木工旋盤を回す）。
  - **建て方**: 簡単には作れず、素材をそれなりに集めて建てる。予定地に普請中の骨組みを置き、材料を少しずつ運び込んで段階的に建てる案（土台（石）→ 柱と梁（ラワン材）→ 壁（竹の下地に土と粘土を塗る土壁）→ 屋根（茅葺き））。段階と材料の数は、作るときに決める。
  - **中に入る**: 建てたら戸口から中に入れ、画面を島から小屋の中に切り替えて操作する。中では、寝床で眠る（シェルターより回復が速い）、収納箱に預ける、作業台などを据えて作れる物を増やす、を候補にする。
  - 水車の隣に据えた[木工旋盤](items/wood-lathe.md)を小屋で囲う形にして、小屋の中に初めからある設備を旋盤にする。
- **旋盤で作る物**: 今は[スポーク車輪](items/spoked-wheel.md)だけ。車輪だけにせず、木の器（葉っぱの代わりに何度でも水を汲める）などを足す。
- **リアカーを広げる**: [リアカー](items/handcart.md)はもうある。あとから荷台の側板を足して積める量を増やす、木材だけを重ねて積めるようにする、などを候補にする。
- **滑車**: ハシゴの所で[リアカー](items/handcart.md)を崖の上へ引き上げる仕掛け（今のリアカーはハシゴを登れない）。
- **竹筏**: 崖の上の湖を渡るための筏。[竹](items/bamboo.md) ×10、[ロープ](items/rope.md) ×4 から、[石斧](items/stone-axe.md)を道具にして作る（長さをそろえて切った竹を並べ、ロープで縛る）。竹は中が空洞で水に浮くので、漂流者が作る舟として現実らしい。湖の上では十字キーで自由に漕いで動け、岸で乗り降りする。向こう岸（火山の裾野へ向かう次のエリア）へ渡るのに使う。湖の南岸の真ん中、ハシゴのほぼ真北には、岸が開けた浜があり、筏を出せそうに見えるようにしてある。
  - 竹は西の海岸（丸太橋で川を渡った先）にしかないので、湖へ進むには「ハシゴで崖の上へ → 松からパイン材 → 丸太橋で西の海岸へ → 竹を切る → 竹筏で湖を渡る」と、行ける範囲を順に広げていくことになる。竹は5本まで重ねられるので、10本はバッグの 1×3 の枠2つ分。竹林のある西の海岸から、湖の南岸があるハシゴ側の崖の上までは、丸太橋と最初のエリアを通って運ぶ。
  - ロープは釣り竿・ハシゴ・丸太橋・水車・竹のスコップ・道具帯とも取り合いになる。竹は水車（竹 ×4）・竹のスコップ（竹 ×1）・リアカー（竹 ×2）とも取り合いになる。
  - 前はパイン材と樹皮のカヌーを考えていたが、材料がすべて西の海岸へ行かずにそろってしまい、西の海岸へ行く意味がなくなるので、竹筏に替えた。
- **土器・土のかまど・レンガ**: [粘土](items/clay.md)と[土](items/soil.md)は掘れるようになった（今の使い道は、土を[狼煙台](items/signal-fire.md)に使うことだけ。粘土はまだ使い道がない）。粘土は湖の南岸で1日に取れる量が決まっていて、土はどこでも何度でも取れる。これを使って、次の物を作れるようにする。材料・作り方は作るときに決める
  - 土器: 粘土を焚き火で焼く。樹皮の鍋は水を沸かすと使い切りだが、土器は道具として残り、何度でも水を沸かせる、という差を付ける
  - 土のかまど: 粘土・土・石で作って据え置く。かまどがあると焼ける物（レンガ、上等な土器）が増える
  - レンガ: かまどで粘土を焼く。水車小屋の土台や窯に使う（水車小屋の仕様とあわせて決める）
- **離れた場所の時間の追いつき**: 島は区画ごとに、最後に動いていた時刻を覚えている（「島」を参照）。区画が動き出すときに、離れていた時間の分だけ蟹が増える・減るなどをまとめて計算する仕組みを入れる。今は何も変わらず、離れたときの状態から続く。
- **資源の再生**: 椰子の実や樹皮、竹は、今は一度取ったら戻らない（戻るのは、茂みの葉、毎朝の貝殻、西の海岸の流木、釣った魚、湖の南岸の粘土の露出）。竹は現実には早く伸びるので、筍から生え戻る形を候補にする。
- **貝殻のほかの用途**: 今は釣り針にだけ使う。水のすくい（葉っぱの代わりに何度でも水を汲める）、ほら貝の笛（船に合図して救助を呼ぶ、脱出ルートの一つ）、焼いて石灰、塩づくりの器、飾りなどが候補。
- **釣りのエサ**: エサ（蟹の身など）を付けると掛かりやすくなる。
- **松明の持ち歩き中の見た目**: 斧を振る・収穫・食事などの動作中は、松明の絵が消える（光は消えない）。
- **竹の使い道**: 竹（[竹](items/bamboo.md)）は西の竹林（坂の上の崖の上まで続く）で取れる。今の使い道は[水車](items/water-wheel.md)・[竹のスコップ](items/bamboo-spade.md)・[リアカー](items/handcart.md)（持ち手の棒）。竹の水筒（水を持ち歩ける）、松脂を集める入れ物、よりよい釣り竿などを候補にし、使い道を取り合いにする。竹筏（上の「竹筏」）に使うことは決めてある。
  - あとから足す候補: 筍（竹林に生えて、掘ると食べられる。掘らずにおくと竹に育つ）。

## ゲームの流れ

1. タイトル画面から始まります。砂浜に倒れた主人公の上に、タイトル（CASTAWAY ISLAND）と START のメニューが出ます。セーブデータがあると、その下に CONTINUE も出ます。上下で選び、START か A で決定します（[セーブと再開](save.md)）。
2. 砂浜に倒れた状態から目を覚まして始まります（A・B ボタンで飛ばせます）。
3. 島を歩いて素材を集め、バッグの CRAFT で道具や食べ物を作ります。
4. 食べる・飲む・眠ることで生き延びながら、できることを増やしていきます。
5. 体力が0になると倒れて、ゲームオーバー（バッドエンド）です。画面が暗くなり、倒れた日時と生き延びた時間が出ます。セーブデータは消え、START でタイトル画面に戻り、最初からやり直せます。
6. 島から脱出するとゲームクリアです。今ある脱出の手段は[狼煙](#狼煙)で、煙が見つかると救助されます。画面が暗くなり、脱出した日と記録が出ます。セーブデータは消え、START でタイトル画面に戻ります。

## 島

今のマップは、島全体のうちの一部のエリア（南の浜辺とその北の森、川の向こうの西の海岸、崖の上の高台と湖）です。今後さらにマップを広げる予定です。以下の広さや配置の数は、今のマップについての値です。

- 今のマップの広さは 208×136 マス（1マス 16px）です。島の中央には火山があり、中央へ向かうほど高くなっていく予定です。
- 島は毎回同じ形です。手で描いた設計図から作ります。設計図・特別な場所・細部の置き方は [島の設計](island.md) を参照してください。
- 地形は、深い海・浅瀬・砂浜・草地・森・ジャングル（茂みの藪）と、崖の上の高台です。高台の上には湖（深い所・浅瀬・湿った土の岸）と、木に覆われた岩山があります。崖が途切れて草の坂になっている所が1か所あります（「西の海岸」）。
  - 浅瀬は歩けますが、遅くなり、走れません。脚が水に隠れます。
  - 深い海・川・崖は通れません（川にかけた丸太橋の上と、崖に立てかけたハシゴは通れます）。
- **最初のエリア**（主人公が流れ着いた場所）は、三方を自然の壁に囲まれていて、歩いては外へ出られません。道具を作って壁を越えていきます。最初のエリアの素材（ラワン材など）で[ハシゴ](items/ladder.md)を作って北の崖の上へ登る → 崖の上の松から[パイン材](items/pine-timber.md)を手に入れる → パイン材で[丸太橋](items/log-bridge.md)を作って西の川を渡る → 西の海岸から草の坂を登って、崖の上の川の西側へ行く、の順です。
  - **西**: 川。橋がなければ渡れません。河口から沖の深い海までは流れが強く、浅瀬を歩いて回り込むこともできません。海の中の流れは河口から沖へ末広がりに深い海へつながっていて、深い海と同じ濃い色で描き、深くて通れないことが見てわかるようにしています。川が1か所だけ狭くなっていて、その両岸は茂みのない空き地です。そこにだけ [丸太橋](items/log-bridge.md) をかけられ、かけると川の向こう（西の海岸と竹林）へ渡れます。橋がかかるのは狭い所の真ん中の行だけですが、その上下3行の岸のどこでかけようとしても、主人公が真ん中まで縦に歩いてからかけます。
  - **北**: 森を抜けると、東西に続く崖です。崖の上は高台で、見えますが登れません。崖が1か所だけ低くなっていて（上の縁が崩れて、草が下へ沈み込んでいる。足元は左右の崖とそろっている）、その前の森は小さく開けた空き地になっています。くぼみのすぐ上の高台には松が1本立っていて、崖の下から見えます。くぼみの真ん中の足元には、その松から転がり落ちた松ぼっくりが1つあります。[ハシゴ](items/ladder.md) が届くのはくぼみの真ん中だけですが、くぼみのどのマスで立てかけようとしても、主人公が真ん中まで横に歩いてから立てかけます。立てかけると崖の上へ登れます。
  - **東**: 北の崖は東の端で向きを変え、南東へ斜めに下る断崖になります。海岸はその断崖に沿って細くなり、断崖は深い海へ突き出した切り立った岬で終わります。岬の先は深い海に囲まれていて、回り込めません。
- **西の海岸**（川の向こう。丸太橋で渡る）: 川の西は森と草地が続き、西の端は南北に続く砂浜で、その先は深い海です。北の高台は西の端で斜めの断崖になって下り、その下を浜が北の端まで続きます。北の断崖は、さらに北では海に直接落ちていて、浜はそこで途切れます。湖の西の岩山は海へせり出していて、海側の縁は南へ段々に引っ込み、砂岩の崖が海に落ちます。浜の奥、北の断崖の下には **竹林** があり、竹が1本ずつ立っています。竹は石斧で切り倒すと[竹](items/bamboo.md)が取れます（最初のエリアにはない資源）。竹林の中には茂みや花は生えません。西の浜にはヤシの木が並んでいます（川の西の浜は細いので、ほかの浜より多く立てている）。竹林の南の森には、小さな藪（ジャングル）が2つあり、その間を通れます。この藪は茂みがまばらで、中も歩けます。川の西側の木や竹のそばには、ツル植物がよく絡んでいます。
  - 竹林の北東では、北の崖の西の端の斜めの崖が途切れて、なだらかな **草の坂** になっています（崖の上の高台と、その下の草地がつながる）。坂を登ると、崖の上の川の西側（北は岩山、東は川、西と南は崖に囲まれた高台）へ行けます。坂の下の竹林は、坂の道中を通って坂の上まで続いていて、崖の上の川の西側は一面の竹林です（広葉樹や松はない）。竹は左右に並ばないので、竹の間を抜けて坂を登り降りできます。坂は高い所ほど明るく、等高線のような濃淡の筋があり、裾は下の草地に溶け込んでいます。坂のすぐ東の崖は、西の端から段々に高くなります。坂とそのまわりには木や茂みがありません。
  - 崖の上の川の西側からは、川を渡れないので、ハシゴを立てた東側へは行けません（逆も同じ）。
- 川は崖の上の湖から流れ出し、崖を **滝** になって落ち、その下の **滝壺** から森と草地を流れて海へ出ます。滝壺の周りは森の中の小さな草地で、川は滝壺の南から流れ出します。滝壺を出た川は、しばらく南へまっすぐ流れ、川の狭い所の手前で1回だけ西へ曲がって、狭い所をまっすぐ南へ抜けます（狭い所の行で川が2マスに収まり、丸太橋がかかるように）。その先は蛇行しながら海へ出ます。滝壺の下のまっすぐな流れの西岸は **水車小屋の予定地** で、その西から川の狭い所の手前まで、木や茂みのない広い草地が続きます（川の向こう。丸太橋で渡ってから）。予定地の岸から、川に[水車](items/water-wheel.md)を据えられ、据えた水車の隣の岸（予定地の岸のマスとその西のマス、水車と同じ2行）に[木工旋盤](items/wood-lathe.md)を据えられます。水車の隣に建てる小屋は、まだありません（「まだコードにないコンセプト」の水車小屋）。滝壺の東の岸と西の岸（川の向こう。丸太橋で渡ってから）に **水汲み場** があります。湖から滝までの崖の上の川の岸にも、もう1か所 **水汲み場** があります（ハシゴで上がってから）。
- **崖の上の湖**: 高台の北には、東西にマップの幅ほどもある大きな湖があります。岸の周りは浅瀬（海の浅瀬と同じで、歩けるが遅く、走れない。魚もいる）で、沖は深くて入れません。岸は海の砂浜と違う、暗い茶色の湿った土で、貝殻・蟹・流木・ヤシの木はありません（海の物なので）。湖の水際には白い波が立ちません。
  - 湖の東西の端は、木や茂みに覆われた **岩山** でふさがれています。岩山は段々に高くなっていて、南の縁や段の縁には黄土色の砂岩の崖が切り立ち、登れません。岩山に面した所は湖が深いままで、浅瀬を歩いて回り込むこともできません。湖の向こう岸（北）へは、今は行けません（「まだコードにないコンセプト」の竹筏）。
  - 湖の東の岩山は、南へ **尾根** になって海まで延びています。崖の上の東の松林は、東を尾根で閉じられていて、尾根の向こう（東）へは行けません。尾根は海に落ちる所で、岬の東に小さな入り江を作ります。
  - 湖の南岸の真ん中（ハシゴのほぼ真北）と、北岸の右寄りに、岸が開けた広めの岸辺があります。
  - 川は湖の南岸から、ラッパのように開いた口で流れ出します。口の前の浅瀬は川の流れになっていて、歩いて渡れません。
- 島の崖（北の崖・断崖・岩山）の岩肌は、黄土色の砂岩です。崖の足元には草がかぶさって伸びます。高台が東西へ落ちる所は、上から見ると縁に沿った細い岩の帯で、草が帯の縁まで続きます。
- 川が浜を横切る所では、両岸の砂が川の水を吸って濡れた暗い帯になっていて、川が運んできた小石が水際に散らばっています（小石は地面の模様で、拾えません）。

### 区画（チャンク）

島は 32×32 マスの区画に分けて扱います。島の地形・置物・採取の状態は全体を常に覚えていますが、画面に出す準備と生き物の動きは、プレイヤーの近くの区画だけで行います。

- **地面のタイル**: 画面とその周り（16px）の区画はすぐに作り、その先（区画の半分＝256px）の区画は1フレームに少しずつ前もって作ります。1フレームに作る量は手間で区切っていて、ふつうのマスなら4行分（128マス）です。川のそばのマス（川の水・岸・滝・河口の流れ）はピクセルごとに川との位置を計算するので、1マスをふつうの8マス分と数えて、そのぶん少ない行数にします（少なくとも1行は作る）。こうして、川の近くを先読みするフレームだけが重くなってカクつくのを防いでいます。画面から1区画分（512px）より離れた区画のタイルは捨てて、VRAM を空けます。
- **生き物の動き**: 蟹・魚・落ちて転がっているアイテムは、画面から256px以内の区画にいるものだけが動きます。画面から320px以上離れた区画は眠り、そこにいるものは止まります。セーブから再開したときは、セーブしたときに動いていた区画がそのまま動き続けます。カモメは空を飛んでいるので、いつも動きます。
- **時間の追いつき**: 眠っていた区画が動き出すときに、眠っていた時間（ゲーム内の分）がわかるようになっています。今はそれを使った変化はなく、止まったときの状態から続きます（「まだコードにないコンセプト」を参照）。
- 焚き火・松明・貝殻と流木の打ち上げ・魚の補充は、時刻で決まるので、区画が眠っていても遅れずに進みます。

## 時間

- ゲーム内の1分は 20 フレーム（1/3 秒）です。1時間は約20秒、1日は約8分かかります。
- 1日目の朝7時から始まります。
- 夜の暗闇は 18:17 頃から翌 5:38 頃まで、約11時間20分続きます。
  - 暗闇の外は真っ暗で、見えるのは光の届く範囲だけです。
  - 光源は、持ち歩いている松明とすべての焚き火で、同時にいくつでも照らせます。
  - 夕方と明け方は、暗くなる前・明るくなった後に空の色が変わります。

## 主人公の状態

### 体力

- 満腹度・水分と同じゲージで、最大は64です（画面左上の一番上、赤いゲージ）。
- **0になると倒れて、ゲームオーバーです。**
- 減り方・戻り方は、すべて「最大量の64分の1が何分で減る（戻る）か」で決めています。最大量が変わっても、倒れるまでの日数は変わりません。

| 状況 | 体力の増減（64分の1あたり） |
|---|---|
| 起きている（疲れ） | 75分で1減る（16時間で約13、ゲージの約5分の1） |
| 走っている（疲れ） | 歩いているときの2倍（37.5分で1減る）。1分のうち走っていた割合に応じて増える |
| 水分が0 | 68分で1減る（起きていても眠っていても） |
| 満腹度が0 | 10時間で1減る（起きていても眠っていても） |
| 眠っている | 15分で1戻る（シェルターの中では10分で1） |
| 眠っている（満腹度か水分が0） | 疲れの分しか戻らない（下を参照） |
| お腹を壊している | 90分で1減る（起きていても眠っていても。「体調」の節） |

- **疲れ**: 画面には出ない値です。起きている1分ごとに1たまり（走っていると2）、眠っている1分ごとに2減ります（8時間眠ると16時間分の疲れが取れる）。
  - 満腹度か水分が0のときは、眠っても疲れが取れた分（起きていて減った分）しか体力は戻りません。それ以上は回復しません。
  - 疲れが取れたあとも眠り続けられますが、何も回復せず、飢えと渇きだけが進みます。
- 起きている16時間ずっと走り回ると約26減りますが、満腹度と水分があれば一晩（8時間で約32戻る）眠ると戻ります。満腹度か水分が0のまま走り回ると、眠っても疲れの分しか戻らないので危険です。
- 焼き蟹・焼き魚を食べる、沸かした水を飲むと、13回復します。満腹度か水分が0のままなら回復しません（沸かした水は飲めば水分が戻るので回復します）。
- 目安（朝7時に満タンから始めた場合）:

| 過ごし方 | 倒れるまで |
|---|---|
| 水も食べ物もあり・普通に眠る | 倒れない（夜に約5分の1減り、一晩眠ると戻る） |
| 水も食べ物もあり・眠らない | 約3.3日 |
| 水がない | 約3〜4日（普通に眠って約3.2日。眠らないと約1.8日） |
| 食べ物がない（水はある） | 約3〜4週間（普通に眠って約23日。眠らないと約3日） |

### 満腹度と水分

- どちらもゲージで、最大は64です。
- 起きているとき、満腹度は15分ごと、水分は10分ごとに1ずつ減ります。
  - 満タンから空になるまで、満腹度は約16時間、水分は約10時間40分です。
- 眠っているとき、満腹度の減り方は起きているときの6分の1（シェルターの中では24分の1）、水分は2分の1（シェルターの中では6分の1）です。眠っていても息で水分は抜けていくためです。シェルターの中では日差しや風を避けられるので、特に水分が抜けにくくなります。
  - 8時間眠ると、外では満腹度が約5・水分が約24減り、シェルターの中では満腹度が約1・水分が約8減ります。
- 走っても、満腹度と水分の減り方は変わりません（体力の減りだけが早くなる）。
- お腹を壊しているあいだは、水分の減りが2倍になります（「体調」の節）。
- 回復量は食べ物・飲み物ごとに決まっています。各アイテムのページを参照してください。
- **満腹度が0のあいだは、弱って走れず、歩く速さも4分の3になります**（歩く足取りもゆっくりになる）。満腹度が1以上に戻ると元に戻ります。

### 体調

- 主人公は、しばらくのあいだ体調を崩すことがあります。今ある体調の悪さは **お腹を壊す** の1つだけです（コードでは `Ailment` に足していける形にしてあり、ケガなどをあとから足せます）。
- **お腹を壊す**: 火を通していない物を口にすると、確率でお腹を壊します。食べた・飲んだその場で始まるので、何のせいかがすぐわかります。

  | 口にした物 | お腹を壊す確率 |
  |---|---|
  | [生水](items/raw-water.md) | 20% |
  | [魚](items/fish.md)（生） | 30% |
  | [蟹](items/crab.md)（生） | 50% |
  | 焼き蟹・焼き魚・沸かした水・割った椰子の実 | お腹を壊さない |

  - お腹を壊しても、口にした物の満腹度・水分は回復します（生のまま口にするのは、危ないと承知で取る手）。
  - ゲームを始めてから **最初に飲む生水は、必ず大丈夫** です（漂着した直後に水が飲めずに詰まらないため）。2回目からは確率どおりです。
  - 6時間（ゲーム内）続き、時間がたつと自然に治ります。眠っても時間は進むので、寝てやり過ごせます。
  - お腹を壊しているあいだにまた当たると、そこから6時間に戻ります。症状は重くなりません。
  - 症状: 水分の減りが2倍になります（起きていても眠っていても）。体力が90分で1（64分の1）減ります（6時間で約4。これだけで倒れることはない）。走れなくなります（歩く速さは変わらない）。
  - 見た目: 顔色（肌の色）が血の気の引いた灰色がかった色になり、片手でお腹を押さえて歩きます（立ち止まっているときも押さえている）。画面左上では、体力のハートとゲージが赤から毒々しい紫に変わり、体力のゲージの右に、横向きに前かがみになってお腹を押さえる人のピクトグラム（ほかのアイコンと同じ 8×8、白）が出ます。治るとどちらも元に戻ります。文字では伝えません。
  - 体力のゲージが紫になるのは、体調の悪さのどれかがあるときです（どの体調の悪さでも同じ）。何の体調の悪さかはピクトグラムで見分けます。ピクトグラムは体力のゲージの右に横に並べます（体調の悪さを足したら、その分右へ並ぶ）。

### 移動

- 歩く（約1.3px/フレーム）、走る（R を押しながら。約2.2px/フレーム）、浅瀬を歩く（約0.7px/フレーム）の3つです。
- 満腹度が0のあいだは走れず、歩く・浅瀬を歩く速さが4分の3になります。
- お腹を壊しているあいだも走れません（歩く速さは変わりません。「体調」の節）。
- 走っているあいだは、疲れがたまるのが歩いているときの2倍になり、体力が早く減ります（「体力」の節）。
- 障害物の角に少し引っかかったときは、自動で横にずらして通り抜けます。
- 川にかけた [丸太橋](items/log-bridge.md) の上は、ふつうの地面と同じように歩けます。
- [リアカー](items/handcart.md)を引いているあいだは、リアカーが真後ろに付き、両手で棒を握るポーズで歩きます。走れません（歩く速さは変わりません）。リアカーは当たり判定に加わらず、引いていないときと同じように歩けます。浅瀬には入れず、ハシゴにも乗れません。ジャングルには入れます（茂みは引いていないときと同じく通れません）。置いたリアカーも通り抜けられます。
- 崖に立てかけた [ハシゴ](items/ladder.md) の上では、上下にだけ動けます（約0.66px/フレーム、歩く速さの半分）。崖のほうを向いて手足を交互に動かして登り、ハシゴの真ん中に寄せられます。ハシゴの上では、道具を使う・拾う・眠るなどはできません。

### 眠る

- L でその場に横になります。浅瀬では眠れません。
  - 押し間違えて寝てしまわないよう（眠ると時間が一気に進む）、よく押す A・B・X・Y ではなく L に割り当てています。
- 眠っている間は、ゲーム内の時間が1フレームに2分ずつ進みます。
- 眠ると体力と疲れが戻ります（「体力」を参照）。
- いつでも好きなだけ眠れますが、満タンでそれ以上は回復しません。そのあいだも飢えと渇きは進みます。
- バッグにシェルターがあると、シェルターを張って中で眠ります。主人公は見えなくなり、シェルターから Zzz が出ます。
  - 体力の戻りが速くなり、空腹と渇きの減りがさらに遅くなります。
- A・B・L のどれかを押すと起きます（Y では起きません）。眠っているあいだと起きたときに自動でセーブします（[セーブと再開](save.md#いつセーブするか)）。

### 操作の手段

- PC ではキーボードかゲームパッドで操作します。
  - ページはゲーム画面だけにし、その上に「CASTAWAY ISLAND」のタイトルと「操作」「表示」のボタン（`?debug=true` のときは「デバッグ」も）を並べます。
  - ページを開くと、ゲーム画面の上に操作説明のダイアログ（ボタンの名前、キーボードのキー、大まかな役割。タッチ端末と同じ一覧）が出ます。「閉じる」か Esc で閉じます。「起動時に表示しない」の扱いはタッチ端末と同じです（下を参照。cookie も同じものを使います）。「操作」ボタンでいつでも開けます。開いている間は、キーはダイアログのもので、ゲームには伝わりません（Enter で閉じられます）。
  - 「表示」（倍率・CRTアスペクト比・走査線・スプライト制限、位置・時刻・VRAM の表示）と「デバッグ」は、画面の右に浮かぶダイアログで開きます。画面を暗くせず、開いたままゲームを操作できるので、変えた結果をすぐ見られます。2つ同時に開けます。右上の「×」か、もう一度ボタンを押すと閉じます。
- ページの文言（操作説明・表示・デバッグのダイアログ、インストールのバナー）は、ブラウザの言語（`navigator.language`）が日本語なら日本語、それ以外なら英語で出します。ゲーム画面の中の文字（START、CRAFT など）は、もとから英語で、切り替えません。
- スマートフォンやタブレット（指で触る端末）では、画面に SFC のコントローラを模したボタンが出ます。ページはゲーム画面とボタンだけになります。
  - 縦向き: ゲーム画面を上に横幅いっぱいに出し、その下に L・R、十字キー（左）と A・B・X・Y（右）、SELECT・START を並べ、右下の隅に「?」を置きます。
  - 横向き: ゲーム画面を真ん中に出し、左に L・十字キー・SELECT、右に R・A・B・X・Y・START を置き、右下の隅（START の右）に「?」を置きます。
  - ページを開くと、ゲーム画面の上に操作説明のダイアログ（ボタンの名前と大まかな役割。PC と同じ一覧で、キーボードのキーは出しません）が出ます。「閉じる」で閉じます。「起動時に表示しない」にチェックを入れて閉じると、ブラウザの cookie（`castaway_skip_touch_help`、約400日）に覚えて、次からは出しません。チェックを入れずに閉じたときは、次に開いたときもまた出ます。
  - 画面の右下の隅の「?」ボタンで、いつでも操作説明を開けます。「起動時に表示しない」のチェックは今の設定から始まり、チェックを外して閉じると、次に開いたときからまた出るようになります。「?」ボタンはゲームのボタンではなく、押してもゲームには何も伝わりません。L や十字キーのそばだと押し間違えやすいので、遊ぶときに触らない右下の隅に置いています。
  - A・B・X・Y は SFC と同じひし形（上が X、左が Y、右が A、下が B）です。
  - 複数の指で同時に押せます（十字キーを押しながら R で走る、など）。十字キーは触れた指の向きで8方向を決め、指を離さずに滑らせて向きを変えられます。斜めは狭く取ってあり、少しずれても斜めになりにくくしています。A・B・X・Y などは、指を滑らせると隣のボタンに乗り移ります。
  - ボタンを押しても振動はさせません（Android の Chrome では短くしても震えている感じが残り、手触りがよくなかったため）。
  - SELECT もありますが、デバッグ用で、`?debug=true` のときだけ時刻を進めます（「デバッグ機能」の節）。それ以外のときは何も起きません。
- ページはホーム画面にアプリとしてインストールできます（PWA。Android の Chrome は「アプリをインストール」、iPhone の Safari は「ホーム画面に追加」）。
  - インストールできることに気づきやすいよう、ページ自身がバナーで知らせます。
    - Android や PC の Chrome など、ブラウザがインストールできると知らせてくる所では、「インストール」と「閉じる」のあるバナーを出します。「インストール」でブラウザのインストールの確認が開きます。すでにインストールしてあるときは、ブラウザが知らせてこないので出ません。
    - iPhone・iPad では、ページからブラウザの確認を開けないので、共有メニューから「ホーム画面に追加」を選ぶ手順をバナーに出します（ボタンは「閉じる」だけ）。ホーム画面のアプリとして開いているときは出しません。
    - バナーはゲームを止めず、キーも奪いません。PC では画面の下、タッチ端末では画面のボタンに重ならないよう画面の上に出します。操作説明のダイアログが出ている間は出さず、閉じたあとに出します。
    - 「閉じる」で閉じると、ブラウザの cookie（`castaway_skip_install`、約400日）に覚えて、もう出しません。そのあとも、インストールできる間は操作説明のダイアログに「アプリとしてインストール」のボタン（iPhone・iPad では手順の文）が出るので、そこからいつでも入れられます。
  - インストールしたものは、ブラウザの枠やアドレスバーのない全画面で開きます（iPhone では状態バーは残ります）。画面の向きは固定せず、縦でも横でも遊べます。アイコンは favicon と同じ、海に浮かぶ小島と椰子のドット絵です。
  - 一度開くと、ページと遊ぶのに要るファイルをすべて端末に取っておくので、次からは電波がなくても遊べます。電波があるときは開くたびに新しい版を確かめ、新しい版があればそちらに入れ替えます（入れ替わった版は次に開いたときから出ます）。
  - セーブはブラウザの localStorage にあるので（[セーブと再開](save.md)）、電波がなくても書けます。ただしインストールしたアプリとブラウザのタブでセーブを共有するかは端末しだいで、iPhone ではホーム画面のアプリはブラウザとは別のセーブになります。

## 釣り

- 浅瀬、川、岸に近い海には魚が35匹、崖の上の湖と川には12匹泳いでいます。昼は水の中に黒い影として見えます。夜は見えませんが、魚はいて、釣ることもできます。
- 釣り方:
  1. 釣り竿を手に持ち、水に向かって B を押すと糸を投げます。目の前の水面（約34〜46px先）にウキが浮きます。投げた先が水でなければ何も起きません。浅瀬に入っている間は投げられません。
  2. ウキから 56px 以内に魚がいると、寄ってきます。ウキに着くと何度か（1〜3回）つついてウキが揺れ、そのあとウキが沈みます。
  3. ウキが沈むと同時に水しぶきが上がります。沈んでいる間（45フレーム、0.75秒）に B を押すと釣れます。魚は水から跳ね上がり、主人公の横の砂に落ちるので A で拾います。
- 失敗するとき:
  - 沈む前に B を押すと、糸を引き上げてしまい、寄ってきた魚は逃げます。
  - 沈んでいる間に押せないと、魚は逃げます。糸はそのまま残り、別の魚を待てます。
  - 移動するか A を押すと、糸を引き上げます。
- 逃げた魚は、しばらく（300フレーム）ウキに寄ってきません。
- 釣った魚の代わりは、3時間後（ゲーム内）に画面の外のどこかに現れます。湖の魚が12匹より少なければ湖に、そうでなければ海や川に現れるので、湖で釣った分は湖に戻ります。
- 釣り針は使っても減りません。

## バッグ

- 6×4 マスの枠に、アイテムをそれぞれの大きさで詰めます。
  - 向きを90度回して入れられます。重ねることはできません。
- 同じ種類の一部は重ねて1か所に入ります（葉っぱは20枚、椰子の殻・ロープ・ヤシの葉・貝殻・松ぼっくり・竹は5つまで、重い粘土・土は3つまで）。重ねられる数は各アイテムのページにあります。
- 背負子を背負うと、2行増えて 6×6 マスになります。
- [リアカー](items/handcart.md)には、バッグとは別に 8×6 マスの荷台があります。CART タブで、バッグとの間で物を移します。
- 道具帯を腰に締めると、手に持つ道具を2本まで帯に提げて、バッグの外で持ち歩けます（「装備」を参照）。
- 入りきらないときはバッグが開き、あふれた物を手に持った状態になります。場所を空けて入れるか、地面に置きます。
- 画面は ITEMS・CRAFT・GEAR の3つのタブに分かれています。リアカーが手元にある（引いている、または置いたリアカーの近くにいる）ときは、GEAR の右に CART が加わって4つになります。セーブは自動で、バッグを閉じたときに持ち物が変わっていればセーブします（[セーブと再開](save.md#いつセーブするか)）。
  - 開くと ITEMS のアイテムの枠にカーソルがあります。
  - L・R で左右のタブへ移り、そのページにすぐ入ります。端のタブより先へは進みません。CART のタブが出ているときは、CART も順に通ります。タブの並びの左右の端に「L」「R」の印を出して、切り替えられることを見せます。タブが5つのときは、タブの間を詰め、「L」「R」の印を画面の端に寄せます。
    - アイテムのコマンドを選んでいる間、レシピの詳細、装備の付け替えを選んでいる間、アイテムを手に持って動かしている間は、L・R では移りません。
    - ITEMS に戻ると、前のカーソルの位置から始まります（CART のページを通ったときは、カーソルを荷台と分け合うので、左上から始まります）。
  - 枠や一覧のいちばん上で上を押すと、タブの並びに移ります。タブの並びでは左右（または L・R）でタブを選び、A か下でそのページに入ります。
  - まだ開いていないレシピがあると、CRAFT のタブの後ろにも「!」が付きます（「レシピを思いつく」を参照）。
  - **ITEMS**: アイテムを選んで使う・持ち替える・動かす・置くことができます。
    - 置く操作は、生水だけは POUR OUT（流す）です。生水は地面に置けません。
    - 道具帯を締めていて鉤が空いていると、提げられる道具には HANG ON BELT（帯に提げる）も出ます。
  - **CRAFT**: レシピ一覧（1ページ8件、左右でページ送り）から選んで詳細画面を開き、要る物と説明を見て作ります（「クラフト」の「作る」を参照）。
  - **GEAR**: 手（HAND）・背中（BACK）・腰（WAIST）の装備を付け替え・外しできます。腰に道具帯を締めていると、その下に帯の鉤が2行並び、提げる道具を選べます。画面の右端に収まらない長い名前は、末尾を「…」（1文字分）で省きます（例: 鉤の行の DIGGING STI…）。
- バッグを開いている間は、ゲーム内の時間が止まります。

### 装備

- **手（HAND）**: 石斧、木の槍、釣り竿、ハシゴ、丸太橋、水車、掘り棒、竹のスコップ。
- 松明は装備ではなく、作ると持ち歩く状態になります。手の装備枠は使わず、道具と同時に持てます（[松明](items/torch.md)を参照）。
  - 手に持つ道具もバッグの中に入ったまま場所を取ります（道具帯に提げた道具は別。下の「腰」）。
  - 手が空いているときに道具を手に入れると、自動で手に持ちます。
- **背中（BACK）**: 背負子。背負っている間はバッグの外に出て、バッグが広がります。
- **腰（WAIST）**: [道具帯](items/tool-belt.md)。締めている間はバッグの外に出ます（バッグの段数は変わりません）。
  - 帯には鉤が2つあり、手に持つ道具を2本まで提げられます（石斧・木の槍・釣り竿・掘り棒・竹のスコップ。ハシゴ・丸太橋・水車は大きすぎて提げられない）。提げた道具はバッグの外に出て、場所を取りません。
  - 提げた道具も持っている物として扱います。手に持てて（GEAR の HAND で選ぶ）、レシピの道具にもなります。
  - 帯を外すと、帯と提げた道具がバッグに戻ります。入りきらなければ外せません。

## クラフト

- レシピは材料（使い切る）、道具（持っていればよく、減らない）、焚き火のそばかどうか、木工旋盤のそばかどうか、の4つで決まります。

### レシピを思いつく

- 始めは、どのレシピも知りません。CRAFT の一覧は空です。
- レシピの材料を **1種類につき1つずつ** 同時にバッグに持つと、そのレシピを思いつきます。
  - 必要な数が揃っていなくても思いつきます。例: シェルターは枯れ枝・ロープ・茅葺きを1つずつ持てば一覧に出て、詳細画面で必要な数（4・2・2）がわかります。
  - 道具と焚き火は条件に含めません。
- 思いついたとき:
  - 主人公の頭上に「！」の吹き出しが約1秒出ます。動作は止まりません。
  - バッグの中でクラフトして思いついたときは、吹き出しは出ず、一覧にすぐ加わります。
- 一覧では、まだ開いていないレシピの名前の後ろに「!」が付きます。一度詳細を開くと消えます。
  - まだ開いていないレシピが1つでもあると、バッグの CRAFT のタブにも「!」が付きます。ITEMS を開いていても、新しいレシピがあることがわかります。
- 一度思いついたレシピは、材料を手放しても一覧から消えません。
- まだ思いついていないレシピは、行も総数も表示しません。
- 思いついたレシピはセーブされます。

### 作り方が2つ以上ある物

- 同じ物を別の材料で作れるレシピがあります（ロープは [椰子の殻 ×2](recipes/rope.md) か [樹皮 ×3 と石器ナイフ](recipes/rope-from-bark.md)）。どちらで作るかはプレイヤーが選びます。自動では決まりません。
- 作り方はそれぞれ別のレシピとして思いつきます。CRAFT の一覧には物ごとに1行だけ出ます。
  - 一覧で明るく表示されるのは、どれかの作り方で今すぐ作れるときです。
  - どれかの作り方がまだ開いていなければ「!」が付きます。
- 詳細画面では、大きさ（SIZE）の横に `< 1/2 >` が出ます（バッグに入らない物では、名前の下の行）。左右キーで作り方を切り替え、A を押すと、表示している作り方で作ります。
  - 矢印の外側の「!」は、その向きにまだ開いていない作り方があることを示します。
  - 作り方を1つしか思いついていないときは、`< 1/2 >` は出ません。ほかの作り方があることは、思いつくまでわかりません。
- 詳細画面は、前にその物を作った作り方で開きます。まだ作っていなければ、1つ目の作り方で開きます。前に作った作り方もセーブされます。

### 作る

- 詳細画面の上には、作る物の名前・大きさ・説明と絵が出ます。説明は、絵に重ならない幅で折り返します（3マス幅の水車などは狭くなります）。
- その下に、要る物を2つの欄に分けて並べます。見出しは白で出します。
  - **MATERIALS**: 使い切る材料。1行ずつ、名前・要る数（NEED）・持っている数（HAVE）を並べます。
  - **TOOLS**: 使っても減らない物。道具と、焚き火・旋盤のそば（`^ A FIRE`・`* A LATHE`）を1行ずつ並べ、HAVE に持っているか・そばにいるかを YES / NO で出します。道具も焚き火・旋盤も要らないレシピでは、この欄を出しません。
  - 2つの欄の間は1行空けます。
  - 要る物の欄は9行（`NEEDS_SHOWN`）の窓で、今のレシピはすべて入ります。入りきらないレシピができたときは上下キーで1行ずつ動かし、上下に続きがあるほうの端に ▲ / ▼ を出します。隠れている所に足りない物があると、▲ / ▼ を赤にして、見落とさないようにします。
- 足りない行が一目でわかるように、色を分けます。
  - 揃っている行: 白。
  - 材料を持っているが数が足りない行: 黄色。
  - まったくない行（材料が0個、道具を持っていない、焚き火・旋盤のそばでない）: 赤で、行の頭に「X」が付きます。色が見分けにくくても、印でわかるようにするためです。
    - 赤は体力のハートと同じパレットを使うので、お腹を壊している間は、ハートと一緒に紫になります（BG3 のパレットに空きがないため）。
  - 足りない行を暗くはしません。暗い色は「関係ない」と読まれて、肝心の行が目に入らなかったためです。
- 操作は、A で作る、B で一覧に戻る、です（画面の下に `A MAKE   B BACK`）。
  - 作れるときに A を押すと、`MAKE STONE KNIFE?` のように聞かれ、操作の表示が `A YES   B NO` に変わります。A でそのまま作り、B なら作らずに詳細画面へ戻ります。
  - 作ったあとも詳細画面は開いたままで、続けて作れます（焚き火で作るときと、バッグに入りきらずに手に持ったときは別）。
  - 今は作れないとき、`A MAKE` は暗くなります。それでも A を押せて、聞き返さずに下のメッセージが出ます。
- 焚き火が必要なレシピでは、主人公がしゃがんで材料を火にかざす動きのあと、出来上がった物がバッグに入ります。
- 足りないときは次のように表示されます。
  - 材料: NOT ENOUGH MATERIALS
  - 道具: MISSING A TOOL
  - 焚き火: NEEDS A FIRE
  - 旋盤: NEEDS A LATHE
  - リアカーをもう持っている: YOU HAVE ONE ALREADY
- 一覧は [recipes/](recipes/README.md) を参照してください。

## 木工旋盤

- [木工旋盤](items/wood-lathe.md)は、据えた水車の隣の岸に据えると、水車の力で回ります（据え方は旋盤のページ）。
- 旋盤の真ん中から 40px 以内（`NEAR_LATHE`）が「旋盤のそば」で、旋盤で作るレシピ（今は[スポーク車輪](items/spoked-wheel.md)）はそこでだけ作れます。
- CRAFT の一覧では、旋盤で作るレシピの名前の後ろに歯車の印（`*`）が付きます。旋盤のそばにいると黄色、離れていると暗くなります。詳細画面の TOOLS の欄には「A LATHE」の行が出ます。
- 旋盤のそばにいると、CRAFT の右上に「* BY THE LATHE」と出ます（焚き火のそばでもあるときは、旋盤のほうを出します）。

## 焚き火

- 火起こし器をバッグで使う（LIGHT FIRE）と、燃料を1つ燃やして、目の前の地面に焚き火を起こします。
  - 燃料は [松ぼっくり](items/pine-cone.md) か枯れ枝です。松ぼっくりを持っていれば先に1個使い、なければ枯れ枝を1本使います（松ぼっくりは燃やすほかに使い道がないため。どちらでも燃える時間は同じ）。
- 起こせないときは次のように表示されます。
  - 燃料（松ぼっくりも枯れ枝も）がない: NOTHING TO BURN
  - 地面が乾いていない、通れない場所: NO DRY GROUND HERE
  - すぐそばに焚き火がある: A FIRE IS ALREADY HERE
- 24時間燃え続け、最後の2時間は火が小さくなります。
- 焚き火から 40px 以内が「焚き火のそば」で、焚き火が必要なレシピを作れます。
- 夜は周りを照らします。
- 燃えている[狼煙台](items/signal-fire.md)は焚き火の代わりになりません（「狼煙」）。

## 狼煙

島から脱出する手段の1つです。毎日狼煙を上げて、運よく見つけてもらえるまで生き延びます。

- [狼煙台](items/signal-fire.md)を作り（石 ×4、木材 ×2、土 ×2。材料はすべて最初のエリアでそろう）、手に持って B で目の前の乾いた地面に据えます。据えた台は焚き火と同じく通り抜けられ（道をふさがない）、動かせません。何台でも据えられます。
- 据えた台に向かって A を押すと、[火起こし器](items/fire-drill.md)で火を起こします（焚き火を起こすときと同じく、しゃがんで弓を引く動き）。[枯れ枝](items/branch.md) 1本（火種）と[ヤシの葉](items/palm-frond.md) 1枚を燃やし、火起こし器は減りません。
  - 火起こし器（バッグか道具帯）・枯れ枝・ヤシの葉のどれかが足りないと、主人公が考える仕草をします。
  - 燃えている台に A を押しても何も起きません（もう1枚くべることはできない）。
- 火を付けると24時間（`signal_fire::BURN_MINUTES`）煙が上がり、燃え尽きると台だけが残ります。また火を付けられます。
- **救助**: 狼煙には、火を付けた日（日付）ごとに1回だけ、通りかかった飛行機か船に煙を見つけてもらえる見込みがあります。見つかる確率は 1/128（`RESCUE_CHANCE`）です。
  - 見つかるかどうかは、火を付けたときに決まります。見つかる場合は、火を付けてから1時間後〜23時間後（`SEEN_FROM`〜`SEEN_UNTIL`）のどこかの時刻に救助が来ます。眠っていても来ます。
  - 同じ日に何台火を付けても、見込みは1回だけです（その日に最初に付けた1台）。
  - 決まった結果と救助の時刻はセーブに入るので、ロードし直しても変わりません。
  - 目安: 毎日火を付けると、救助までは平均128日（半分の人は約89日目まで、10日で約7.5%、30日で約21%）。宝くじのような、当たればラッキーの手段です。
- 救助されると、ゲームクリアです。セーブデータは消え、画面が暗くなって記録が出ます。START でタイトル画面に戻ります。
  - 今は救助の場面が仮のもので、画面が暗くなり、RESCUED と THE SMOKE WAS SEEN が出るだけです（「まだコードにないコンセプト」）。
- **記録**（脱出したときに出る。脱出の手段が増えても共通）:
  - 脱出した日（ESCAPED ON DAY N）
  - 作ったアイテムの種類 / 作れるアイテムの種類（ITEMS MADE。作れる種類は26。作り方が2つあるロープは1種類と数える）。一度でも作った物を1種類と数えます（焼く・沸かす物、松明、リアカーも含む）。
  - 思いついたレシピ / 全レシピ（RECIPES FOUND。全レシピは27。ロープの2つの作り方は別々に数える）
- 燃えている狼煙台は焚き火の代わりになりません。煙が多すぎて焼く・沸かすには向かないので、そばにいても焚き火が必要なレシピは作れず、夜の明かりにもなりません。
- 見た目: 火を付けると、台の上のヤシの葉が焦げて小さな火が出て、太い煙の柱が高く昇ります（焚き火の火の粉よりずっと目立つ）。煙は昇るにつれて膨らみ、風で東へ流れ、上のほうで薄れて消えます。昼は煙が半透明に見え、夜はほとんど見えません。

## デバッグ機能

- URL に `?debug=true` を付けると、PC の画面に「デバッグ」ボタンが出て、デバッグのダイアログを開けます（タッチ操作の画面には出しません）。好きなアイテムを個数を指定してバッグに入れられ、全レシピを解放するボタンもあります。体力・満腹度・水分を満タンにする、満腹度や水分を0にする、体力を1にするボタンもあります。お腹を壊した状態にするボタンと、体調を元に戻すボタンもあります。主人公を好きなマスへ移す欄と、決まった場所（漂着地点・水汲み場・川の狭い所・水車小屋の予定地・崖のくぼみ・湖の南岸・西の草の坂・東の尾根の前・東の岬）へ移す一覧もあります。立てないマスを指定すると、いちばん近い立てるマスへ移します。
- デバッグのダイアログの一番上の「いまの場所」には、主人公が今いるマス、足元のピクセル位置、向きと、直近1秒に描いたフレームについて、ページがゲームの処理（進める・描く・画面に出す）にかけた時間の平均と最大、描いた回数（fps）が出ます。最大がゲームの1フレームの枠（60Hz で約16.6ms）を超えると、その行が目立つ色になります。fps は画面のリフレッシュレート（多くは60）で頭打ちになり、枠を超えるまで下がらないので、余裕が減ってきたのを見るには処理時間のほうを見ます。重い場所・通れるはずなのに通れない場所・見た目がおかしい場所を探して直すための情報集めに使います。
  - 「コピー」で、その場所を1行（`cell (x, y) px (x, y) facing up · day 2 07:30 · frame 2.1ms avg / 9.8ms max · 60 fps · VRAM 40.1 KiB`）と、同じマス・同じ時刻を描くスナップショットのコマンド（`SNAP_AT` と `SNAP_HOURS`）にしてクリップボードに入れます。この文はページの言語によらず英語です。`pnpm dev` は wasm をデバッグビルドするので処理時間が実際より長く出ます。重さを比べるときは `pnpm build` と `pnpm preview` で開いた画面に `?debug=true` を付けて測ります。
  - 「マス欄に入れる」で、今いるマスを移動のマス欄に入れます。
  - 種類（重い・通れない・見た目・その他）とメモを付けて「記録」すると、記録した場所の一覧にたまります。「全部コピー」で一覧をまとめてクリップボードに入れられ、1つずつ消すことも、全部消すこともできます。一覧はそのブラウザ（localStorage）にだけ残り、セーブデータには入りません。
- `?debug=true` のときだけ、Shift（SELECT。ゲームパッドの SELECT、タッチ操作では画面の SELECT ボタンも）で時刻を3時間進められ、O で服装を切り替えられます。この2つのキーの説明もデバッグのダイアログに出ます。`?debug=true` がないときは、ページ側（JS）がこの2つの入力を wasm に渡さないので、何も起きません（wasm 自身はデバッグモードを区別していません）。
- URL に `?touch=true` を付けると、PC でもタッチ操作の画面（画面上のボタン）になります。`?touch=false` を付けると、タッチ端末でも PC の画面になります。
- 開発用のスナップショットツールについては、リポジトリ直下の [README](../README.md) を参照してください。
